# Case 03: Teams コピペテキスト入力

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "この文字起こしから議事録を作って"（テキスト直接貼り付け） |
| 入力形式 | 直接テキスト（ファイルではない） |
| テキスト内容例 | 下記参照 |

```
田中太郎 15:00
こんにちは、本日もよろしくお願いします。
鈴木花子 15:00
よろしくお願いいたします。
田中太郎 15:01
それでは、まず前回の振り返りから始めましょう。
```

## 期待動作

1. ファイル拡張子がないため、拡張子判定をスキップする
2. 先頭行が `WEBVTT` ではないため、VTT 判定をスキップする
3. 先頭行が「数字のみ + 次行に `-->`」ではないため、SRT 判定をスキップする
4. `名前 HH:MM` の行パターン（`田中太郎 15:00`）を検出し、Teams コピペパーサーを選択する
5. 貼り付けテキストを `inputs/transcript_raw.txt` に保存する
6. 「名前 HH:MM」行を発話者名・タイムスタンプとして、次の行をテキストとして抽出する
7. 分単位タイムスタンプ `HH:MM` を `HH:MM:00` に拡張する
8. 標準形式に変換して `workspace/transcript.txt` と `workspace/metadata.json` を出力する
9. `metadata.json` の `source` フィールドに `"teams-paste"` を設定する

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| `inputs/transcript_raw.txt` | ユーザーが貼り付けた元テキストがそのまま保存される |
| `workspace/transcript.txt` | `[15:00:00 - 15:00:00] 田中太郎: こんにちは、本日もよろしくお願いします。` 等の標準形式 |
| `workspace/metadata.json` | `source: "teams-paste"`, `participants` に田中太郎・鈴木花子を含む |
| 終了状態 | 成功 |

## 分岐の根拠

SKILL.md「形式自動判定の優先順」の第4優先: 行パターン `名前 HH:MM` の合致 → Teams コピペ。`references/format-detection.md` のフローチャートで、拡張子・先頭行の判定がすべて不一致の後、行パターンで Teams 形式を検出する。
