# Case 04: プレーンテキスト（フォールバック）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "この文字起こしテキストを議事録にして" |
| 入力形式 | `.txt` ファイルまたは直接テキスト |
| テキスト内容例 | 下記参照 |

```
こんにちは、本日もよろしくお願いします。
よろしくお願いいたします。
それでは、まず前回の振り返りから始めましょう。
前回のアクションアイテムは全て完了しています。
ありがとうございます。では次の議題に移ります。
```

## 期待動作

1. ファイル拡張子が `.txt` または拡張子なし。`.vtt` `.srt` ではないため拡張子判定は不一致
2. 先頭行が `WEBVTT` ではない → VTT 判定スキップ
3. 先頭行が「数字のみ + 次行に `-->`」ではない → SRT 判定スキップ
4. `[HH:MM:SS - HH:MM:SS]` パターンがない → ailead 形式判定スキップ
5. `名前 HH:MM` パターンがない → Teams コピペ判定スキップ
6. すべての判定が不一致のため、プレーンテキストとしてフォールバック処理する
7. 発話者名を `Unknown` で補填し、タイムスタンプを `00:00:00` で補填する
8. 標準形式に変換して `workspace/transcript.txt` と `workspace/metadata.json` を出力する
9. `metadata.json` の `source` フィールドに `"plain"` を設定する

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| `workspace/transcript.txt` | `[00:00:00 - 00:00:00] Unknown: こんにちは、本日もよろしくお願いします。` 等の標準形式（タイムスタンプ・発話者は補填値） |
| `workspace/metadata.json` | `source: "plain"`, `system: "unknown"`, `duration: 0`, `participants` に `Unknown` のみ |
| 終了状態 | 成功（ただしメタデータ不足のためユーザー確認が後続する可能性が高い） |
