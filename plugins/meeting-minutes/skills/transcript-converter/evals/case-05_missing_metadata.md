# Case 05: メタデータ不足によるユーザー確認

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "この文字起こしから議事録を作って"（テキスト直接貼り付け） |
| 入力形式 | 直接テキスト（ファイルパスなし・ファイル名による推定不可） |
| テキスト内容例 | 下記参照 |

```
こんにちは。
今日の議題は新サービスの価格設定についてです。
月額1000円を提案します。
```

## 期待動作

1. テキスト入力のため拡張子判定不可。パターン判定の結果、プレーンテキストとしてフォールバックする
2. Python スクリプトで変換を実行し、`workspace/transcript.txt` と `workspace/metadata.json` を生成する
3. 以下のメタデータが推定不能であることを検出する:
   - `title`: ファイル名がないため推定できない
   - `startDatetime`: タイムスタンプがないため推定できない
   - `participants`: 発話者名が抽出できないため不明
4. `AskUserQuestion` を使用してユーザーに不足情報を確認する:
   - 会議タイトル
   - 会議日時
   - 参加者（任意）
5. ユーザーの回答を `metadata.json` に反映する

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| ユーザーへの質問 | 「会議タイトルを教えてください」「会議の日時を教えてください」等の具体的な質問 |
| `workspace/metadata.json` | ユーザーの回答に基づいて `title`, `startDatetime` が設定される |
| `workspace/transcript.txt` | 標準形式に変換済み（補填値を使用） |
| 終了状態 | 成功（ユーザーへの確認完了後） |
