# case-09 形式自動判定失敗時のフォールバック

形式自動判定が失敗し、プレーンテキストフォールバックで処理するエラーケース

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "この文字起こしを変換して" |
| モード | 対話 |
| 既存状態 | VTT/SRT/Teams/ailead いずれのパターンにも一致しないテキストが提供される |

## 期待

- transcript-converter スキルが起動される
- 形式自動判定で VTT/SRT/Teams/ailead のいずれにも一致しない
- プレーンテキストフォールバックで処理する
- メタデータ（タイトル・日時等）が推定不能のため、ユーザーに確認する
- workspace/ に transcript.txt と metadata.json を出力する

## 期待出力

| 出力 | 内容 |
|-----|------|
| 成果物 | workspace/transcript.txt と workspace/metadata.json（プレーンテキストフォールバックで変換） |

## 分岐の根拠

SKILL.md「重要な制約」の「形式自動判定が失敗した場合はプレーンテキストとしてフォールバックする」分岐。対応入力形式のいずれにも一致しない場合の安全な処理パス。
