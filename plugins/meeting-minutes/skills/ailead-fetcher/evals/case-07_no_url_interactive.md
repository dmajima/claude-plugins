# Case 07: URL 未指定での対話モード起動

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | 「ailead のデータを取得して」（URL 指定なし） |
| 入力 URL | なし（引数が空、または ailead 共有 URL の形式に合致しない文字列） |
| リンク状態 | 判定不能（URL 未提供のため） |

## 期待動作

1. 引数を確認し、ailead 共有 URL（`https://dashboard.ailead.app/share/...` 形式）が含まれないことを検出する
2. 対話モードに遷移する
3. ユーザーに ailead 共有 URL を AskUserQuestion で確認する:
   - 「ailead の共有リンク URL を入力してください」等のプロンプトを提示する
   - URL の形式例（`https://dashboard.ailead.app/share/...`）を提示する
4. ユーザーから有効な URL が提供された場合、通常のデータ取得フロー（case-01 の正常パス）に遷移する
5. ユーザーがキャンセルした場合、処理を中断する

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| ユーザーへの質問 | ailead 共有 URL の入力を求めるプロンプト。URL の形式例を含む |
| URL 提供後 | case-01_success.md と同じ正常取得フローを実行し、`workspace/` に 4 ファイルを出力する |
| キャンセル時 | 処理中断。`workspace/` にファイルは生成されない |
| 終了状態 | ユーザーの回答待ち → 回答後に正常パス or 中断 |

## 分岐の根拠

SKILL.md「実行モード判定」表: 「URL なし or 不正形式 → 対話 → ユーザーに URL を確認」に該当。ailead 共有 URL が引数で指定されていない場合、スキルは自動でデータ取得を開始できないため、ユーザーに対話的に URL を確認する。
