# Case 06: パスワード保護リンク（未対応）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "この ailead の共有リンクから議事録を作って https://dashboard.ailead.app/share/<key>" |
| 入力 URL | `https://dashboard.ailead.app/share/<パスワード保護された share-key>` |
| リンク状態 | 有効期限内だが、パスワード保護が設定されている |

## 期待動作

1. URL から share key を抽出する
2. HTML ページを `Invoke-WebRequest` で取得する
3. HTML の内容がパスワード入力フォームを含む画面であることを検出する（通常の `__NEXT_DATA__` に `externalShare` データが含まれない、またはパスワード認証エンドポイント `GET /api/v1/share/password?key=<key>` への誘導が含まれる）
4. `buildId` の抽出は成功する可能性があるが、GraphQL API を呼び出しても認証なしではデータを取得できない
5. パスワード保護リンクであることをユーザーに報告し、以下を伝える:
   - このリンクにはパスワード保護が設定されていること
   - パスワード認証フローは本スキルの現バージョンでは未実装であること
   - 対処方法: ailead 側でパスワード保護を解除した共有リンクを再発行するか、パスワードなしの共有リンクを取得するよう案内する
6. 処理を中断する（パスワード認証を試みない）

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | なし（エラーのため出力しない） |
| ユーザーへの通知 | 「この共有リンクはパスワード保護されています。パスワード認証フローは現バージョンでは未実装です。ailead でパスワード保護を解除したリンクを再発行してください。」等のエラーメッセージ |
| 終了状態 | エラー終了（未実装機能のため処理不可。ユーザーに原因と代替手段を明示） |

## 分岐の根拠

`references/procedures.md` エラーハンドリング表: 「パスワード要求: ユーザーにパスワードを確認（未実装）」。`references/api-spec.md` セクション5「パスワード保護されたリンク」: パスワード認証エンドポイント `GET /api/v1/share/password?key=<share-key>` が存在するが、「パスワード認証のフローは本スキル初回バージョンでは未実装。必要に応じて今後追加する」と明記されている。
