# 突合検証ルール

ailead のトピック要約（`callSummary.topics`）を議事録のベースとする際に、
文字起こし全文（`transcripts`）と突合して行う検証のルール。

## 1. 検証の目的

ailead の AI 要約は高品質だが、以下のリスクがある:

| リスク | 説明 | 影響 |
|-------|------|------|
| 事実の歪曲 | AI が文脈を誤解し、実際の発言と異なる要約を生成 | 議事録の信頼性低下 |
| 重要発言の漏れ | トピックに含まれないが重要な議論・合意が存在 | 意思決定の追跡不能 |
| 発言者の誤帰属 | 発言を別の参加者に帰属 | 責任の所在が不明確 |
| 決定事項の見落とし | 暗黙的な合意や条件付き決定の検出漏れ | アクションの追跡漏れ |
| アクションアイテムの欠落 | 「次回までに確認する」等の曖昧な約束の見落とし | タスク漏れ |

## 2. 検証プロセス

### Step 1: トピック単位の突合

ailead の各トピック（`callSummary.topics`）について:

1. **時刻範囲の特定**: トピックの `dateTime` を起点に、前後の文字起こしセグメントを特定する
2. **要約の正確性検証**: トピックの `description` が文字起こしの内容と一致するか確認する
3. **発言者の検証**: トピックの `speakerName` が実際の発言者と一致するか確認する
4. **カテゴリの妥当性確認**: SHARE/DISCUSSION/DECISION/CONCERN/SUGGESTION/DIALOGUE/SCHEDULE のいずれが適切か

### Step 2: 漏れの検出

文字起こし全文を通読し、以下がトピックに含まれていないか確認する:

- **明示的な決定**（「～にしましょう」「～で決定」「～でいきます」等）
- **アクションの割当**（「～さん、確認お願いします」「次回までに～」等）
- **重要な懸念・リスク**（「課題は～」「問題は～」「注意が必要」等）
- **合意形成**（「認識合わせ」「了解」「承知しました」等）
- **前提条件・制約**（「ただし～」「条件として～」「～の場合は」等）
- **数値・期限**（金額・日付・期間等の具体値）

### Step 3: 修正・補完

検証で発見した問題を以下の方針で修正する:

| 発見 | 対処 |
|-----|------|
| 要約が不正確 | 文字起こしに基づいて修正し、修正理由を検証ログに記録 |
| トピックに漏れ | 新規トピックとして追加し、追加理由を検証ログに記録 |
| 発言者の誤帰属 | 正しい発言者に修正 |
| 決定事項の見落とし | 「決定事項」セクションに追加 |
| アクションアイテムの欠落 | 「アクションアイテム」セクションに追加 |

## 3. 検証ログのフォーマット

検証結果は `workspace/verification-log.md` に記録する。

```markdown
# 突合検証ログ

## 検証サマリー

| 項目 | 件数 |
|------|------|
| ailead トピック数 | {{N}} |
| 正確と判定 | {{N}} |
| 修正 | {{N}} |
| 追加トピック | {{N}} |
| 追加決定事項 | {{N}} |
| 追加アクションアイテム | {{N}} |

## 修正・追加の詳細

### [修正] トピック: {{トピック名}}

- **ailead の要約**: {{元の description}}
- **問題点**: {{何が不正確か}}
- **修正後**: {{修正した内容}}
- **根拠**: 文字起こし [HH:MM:SS] 付近の発言「{{引用}}」

### [追加] トピック: {{追加トピック名}}

- **根拠**: 文字起こし [HH:MM:SS] 付近の発言「{{引用}}」
- **追加理由**: {{なぜ重要か}}
```

## 4. 判断基準

### 追加すべきトピックの基準

以下の **いずれか** に該当する議論は、ailead トピックに含まれていなくても追加する:

- 明示的な決定が行われた
- 具体的なアクションアイテムが発生した
- 複数の参加者が発言を交わした（一方的な説明ではない）
- 数値・期限・金額等の具体値が決まった
- 次回以降の進め方に影響する合意があった

### 追加しないもの

- 雑談・アイスブレイク
- 音声の乱れ・聞き取り不能部分
- 同じ内容の繰り返し（既にトピックでカバー済み）
- 「はい」「そうですね」等の相槌のみの発言

## 5. 文字起こしの時刻参照

ailead の文字起こしの `startTime`/`endTime` は正規化値（0.0〜1.0）。
実時刻は `duration`（秒）を乗算して算出する。

```
actual_seconds = startTime * duration
HH:MM:SS = format_time(actual_seconds)
```

トピックの `dateTime` は秒単位の値（正規化ではない）。
