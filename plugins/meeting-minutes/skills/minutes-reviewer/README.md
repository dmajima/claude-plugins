# minutes-reviewer

構造化議事録データを元の文字起こしと突合検証し、漏れ・誤り・発言者帰属の誤りを検出するレビュースキル。

## このドキュメントについて

本ファイルは人間向けリファレンスであり、Claude の動作では使用されない。

## 使い方

minutes-composer の出力後、docx 変換前のレビューステップとして実行される。

```
議事録をレビューして
```

作成時のバイアスを排除するため、必ずフレッシュなサブエージェントとして起動される。
メインコンテキストで作成した Claude が自身でレビューすることはない。

## 検証項目

| 項目 | 内容 |
|------|------|
| トピック正確性 | 各議題の要約が文字起こしと一致するか |
| 漏れ検出 | 決定事項・アクションアイテムの網羅性 |
| 発言者帰属 | 議論内容が正しい発言者に帰属しているか |
| 数値・固有名詞 | 金額・日付・システム名等の具体値が正確か |
