# Case 03: 引数なしで起動

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | `/minutes-md` または `/minutes-docx`（引数なし） |
| `$ARGUMENTS` | 空 |
| 引数の種類 | なし |

## 期待動作

1. `$ARGUMENTS` が空であることを検出する
2. ユーザーに入力方法を確認する。以下の選択肢を提示する:
   - ailead の共有リンク URL を入力する
   - VTT/SRT ファイルのパスを指定する
   - 文字起こしテキストを直接貼り付ける
3. ユーザーの回答に応じて適切なスキルを起動する:
   - ailead URL が提供された場合 → `meeting-minutes:ailead-fetcher` を起動する
   - ファイルパスが提供された場合 → `meeting-minutes:transcript-converter` を起動する
   - テキストが直接貼り付けられた場合 → `meeting-minutes:transcript-converter` を起動する
4. 以降は case-01 または case-02 と同じパイプラインを実行する

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| ユーザーへの質問 | 「議事録の元データをどのように提供しますか？」等の入力方法選択。具体的な選択肢（ailead URL / ファイル / テキスト貼り付け）を提示する |
| ユーザー回答後 | 回答内容に応じた適切なスキルが起動され、フルパイプラインが実行される |
| 終了状態 | ユーザーの回答待ち → 回答後にパイプライン実行 → 成功 |

## 分岐の根拠

`commands/minutes-md.md` および `commands/minutes-docx.md` の「1. データ取得」セクション: 「引数の内容を判定し、適切なスキルを起動する」表の「空 → ユーザーに入力方法を確認」行に該当。`$ARGUMENTS` が空の場合、コマンドはデータソースを自動判定できないため、ユーザーに対話的に確認する。

- `case-02_command_with_file.md`（ファイルパス引数の場合 -- ユーザーがファイルパスを回答した場合の後続パスと同一）
