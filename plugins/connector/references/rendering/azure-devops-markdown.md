# Azure DevOps レンダリングルール（PR / 作業項目）

Azure DevOps（クラウド / オンプレ TFS・Azure DevOps Server）への投稿で適用されるレンダリングルールと、投稿前チェックで検出すべきパターン。**投稿先（PR 系 / 作業項目系）でレンダリングエンジンが異なる** 点に注意する。

## 1. 投稿先別のフォーマット

| 投稿先 | フォーマット | 備考 |
|-------|------------|------|
| PR 説明（description） | Markdown（GFM 近似） | クラウド / TFS 共通 |
| PR コメント（スレッド） | Markdown（GFM 近似） | クラウド / TFS 共通 |
| 作業項目コメント（クラウド: comments API） | Markdown 対応 | `api-version=7.1-preview.4` 系 |
| 作業項目コメント（TFS: `System.History`） | **HTML**（Markdown は解釈されない） | `## 見出し` 等はそのまま文字表示される |

**TFS の作業項目コメントに Markdown 本文をそのまま投稿してはならない**。`System.History` 経由の投稿では、改行は `<br>`、強調は `<b>`、コードは `<pre>` 等の HTML タグで表現するか、装飾なしの平文に変換する。

## 2. サポートされる Markdown 構文（PR 系）

GFM 近似。見出し・リスト・太字・斜体・打消し・コードフェンス・インラインコード・引用・表・リンク・タスクリストが標準どおりレンダリングされる。一部の HTML タグ（`<br>` 等）も許容される。

## 3. 自動リンク・通知（投稿前に必ず確認）

| パターン | 挙動 | リスク |
|---------|------|-------|
| `#123` | **作業項目への自動リンク化** | コード片（`#define`、issue 番号引用、色コード `#fff` の直後の数字等）で意図しないリンク |
| `!123` | **同一リポジトリの PR への自動リンク化** | `!important` 等とは異なり数字が続く場合のみだが、ログ引用で発火しうる |
| `@<ユーザー名>` | メンション（**対象ユーザーに通知が飛ぶ**） | コード中のデコレータ・アノテーション（`@Override` 等）で意図しない通知 |
| URL | 自動リンク化 | 概ね無害。内部 URL の露出に注意 |

**保護方法（優先順）**:

1. コード・ログの引用はコードフェンスまたはインラインコードで囲む（フェンス内では発火しない）
2. 地の文でリンク化を避けたい場合はエスケープする: `\#123` / `\!123` / `` `@name` ``

## 4. 検出パターン（render-check が使用）

| 検出パターン（正規表現） | 内容 | 判定 |
|------------------------|------|------|
| コードフェンス外の `(^|\s)#[0-9]+` | 作業項目自動リンク | WARN（意図的なリンクなら問題なし） |
| コードフェンス外の `(^|\s)![0-9]+` | PR 自動リンク | WARN |
| コードフェンス外の `(^|\s)@[A-Za-z]` | メンション（通知発生） | WARN（**通知が飛ぶことを明示してユーザー確認**） |
| `\{code(:[a-z0-9]+)?\}` / `''[^']+''` / `\[\[[^\]]+>[^\]]+\]\]` | Backlog 記法の混入 | FAIL |
| コードフェンスの開閉不一致（バッククォート 3 つの行が奇数個） | フェンス未クローズ（以降全体がコード表示になる） | FAIL |
| ターゲットが TFS 作業項目コメントで Markdown 構文（`^#{1,6} ` / フェンス / `\*\*.+\*\*`）を含む | TFS `System.History` は Markdown 非解釈 | FAIL（HTML / 平文への変換を提案） |

判定の意味は `render-check` スキルの判定区分（FAIL = 投稿ブロック / WARN = ユーザー判断）に従う。

## 5. TFS 作業項目コメント（System.History）向け変換表

| Markdown | HTML 変換 |
|----------|----------|
| `## 見出し` | `<b>見出し</b>` |
| `**太字**` | `<b>太字</b>` |
| コードフェンス | `<pre>` ... `</pre>` |
| `- 項目` | `<ul><li>項目</li></ul>` または `・項目` |
| 改行 | `<br>` |
| `[テキスト](URL)` | `<a href="URL">テキスト</a>` |

## 6. その他の注意

- PR 説明の上限はおよそ 4,000 文字（超過分は切り捨てられる）。長文はコメントへの分割を提案する（WARN）
- 外部画像 URL・`<img>` タグ・危険スキーム（`javascript:` / `data:`）は投稿前に除去する（FAIL）
- 絵文字ショートコード（`:smile:` 等）はクラウドでは展開されるが TFS のバージョンによっては素通しになる（WARN 扱いにはしない・参考情報）
