# Case 07: ユーザー直接の PR 情報取得（パターン A・読み取り）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | 「GitHub PR https://github.com/owner/repo/pull/42 の情報を見せて」 |
| 引数 | PR URL |
| フラグ | なし |
| 既存状態 | `gh auth status` で認証済み。PR #42 は open |

## 期待動作

1. パターン A（ユーザー直接）と判別
2. `gh` CLI で PR メタ情報を取得
3. 取得結果の要点を **整形してユーザーに報告**

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | なし |
| 標準出力（要約） | PR タイトル・作成者・ステータス・変更ファイル数・レビュアー情報を整形表示 |
| 終了状態 | 成功 |

## 分岐の根拠

パターン A の読み取り。書き込み系（case-01〜06）との分岐。
