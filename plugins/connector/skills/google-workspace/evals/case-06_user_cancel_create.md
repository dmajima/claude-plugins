# case-06: 作成中止

## 入力

```
Google Drive に新しいスプレッドシートを作成して
```

## 期待される動作

### Phase 1: 操作判定
- 操作種別: 書き込み（ファイル作成）

### Phase 2: 承認
- `AskUserQuestion` で作成内容を提示
- ユーザーが「中止」を選択

### Phase 3: 中断
- 「作成を中止しました」と報告
- MCP ツールは呼び出さない

## 分岐根拠

AskUserQuestion の選択 = 中止。書き込みゲートで承認が得られない場合は create_file を発行せず終了する。
