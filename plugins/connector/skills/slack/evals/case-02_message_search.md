# case-02: メッセージ検索

## 入力

```
Slack で先週のデプロイに関するメッセージを検索して
```

## 期待される動作

### Phase 1: 操作判定
- 操作種別: 読み取り（メッセージ検索）
- パブリックチャンネル検索（`slack_search_public`）を使用

### Phase 2: 検索クエリ構築
- `query: "デプロイ after:YYYY-MM-DD"` （先週の日付を算出）
- `sort: "timestamp"` で時系列順

### Phase 3: 結果報告
- メッセージ内容・送信者・チャンネル・タイムスタンプを報告

## 分岐根拠

日付修飾子を含む検索クエリの構築パターン。
