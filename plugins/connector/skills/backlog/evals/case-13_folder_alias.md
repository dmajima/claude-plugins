# Case 13: フォルダ一覧取得（エイリアス URL・ツリー走査）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "このフォルダの中身を見せて https://example.backlog.jp/alias/file/9876543" |
| 引数 | エイリアス URL（フォルダ） |
| フラグ | なし（対話モード） |
| 既存状態 | `~/.claude/credentials.json` に `domains` に `example.backlog.jp` を含む API キーエントリが存在する。プロジェクトキー `PROJ` は会話文脈から既知 |

## 期待動作

### Phase 1: 認証事前確認

- URL からスペースホストを `example.backlog.jp` に確定する
- credentials.json で API キーの存在を確認する

### Phase 2: 操作種別判定

- URL パスに `/alias/file/` を含むため **共有ファイル操作**（読み取り）と判定する
- エイリアス URL からファイル ID `9876543` を抽出する

### Phase 3: エイリアス解決

- プロジェクトキー `PROJ` を会話文脈から取得する（不明な場合は `AskUserQuestion` で確認）
- まず download API（ファイル向け）を試行: `GET /api/v2/projects/PROJ/files/9876543` → 404（フォルダのため）
- フォルダと判定し、ツリー走査に切り替える

### Phase 4: ツリー走査

- ルートまたはユーザーが示したおおよそのパスからディレクトリを走査する
- 各階層で `GET /api/v2/projects/PROJ/files/metadata/{path}` を呼び出し、レスポンスの `id` フィールドが `9876543` と一致するエントリを探す
- 一致するエントリが見つかったら、そのパスで `files/metadata` を呼び出してフォルダ内容を取得する

### Phase 5: 整形報告

- フォルダ内のファイル・サブディレクトリの一覧表を提示する:
  - 名前 / 種別（ファイル or [フォルダ]）/ サイズ / 更新日時

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | なし |
| 標準出力（要約） | フォルダ内のファイル・サブフォルダの一覧表の整形報告 |
| 終了状態 | 成功 |

## 分岐の根拠

このケースが分岐するトリガーはエイリアス URL + download API 404（フォルダ）。case-11（エイリアス URL + download API 200 = ファイル）とは download API のレスポンスで分岐する。フォルダの場合はツリー走査という追加ステップが必要。
