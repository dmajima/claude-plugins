ユーザの引数: $ARGUMENTS

connector プラグインの `projectboard` スキルを **タスク更新** で起動してください。
変更前 → 変更後の提示と AskUserQuestion 承認を経てから updateNodeContent API を実行します。

## 動作

1. `Skill` ツールで `connector:projectboard` を起動し、引数とともに操作種別を明示して渡す:

   ```text
   Skill(skill: "connector:projectboard", args: "タスク更新（タイトル・ステータス・進捗・日付・担当者・先行タスク等）。対象と変更内容: $ARGUMENTS")
   ```

2. 対象ノードの特定・ステータス名 → id の解決・先行タスクの既存値とのマージは
   スキル側が現状のシートを読み取ったうえで行う

## 引数が空の場合

ユーザに以下を確認する:

- 対象タスク（タスク ID / タイトル）と対象シート（URL 等）
- 変更するフィールドと変更後の値（例: ステータスを実行中に、進捗を 50% に）

## 制約

- **ユーザー承認なしで更新を実行しない**（変更前の値を取得・提示してから承認を得る）
- 指定されたフィールドのみ更新する（他フィールドを巻き込まない）
- 更新後はシートを再取得して反映を検証する（書き込み API の一部は推定仕様のため必須）
- 複数タスクの一括更新はユーザーの明示指示 + 対象一覧の承認がある場合のみ
- `git commit` 以降の操作はこのコマンドからは実行しない
