ユーザの引数: $ARGUMENTS

connector プラグインの `backlog` スキルを **読み取り専用** で起動してください。このコマンドは操作種別を明示する入口であり、認証確認・API 実行・結果整形はスキル側の定義に従います。

## 動作

1. `Skill` ツールで `connector:backlog` を起動し、引数とともに操作種別を明示して渡す:

   ```text
   Skill(skill: "connector:backlog", args: "読み取りのみ（検索 / 課題取得 / コメント取得 / ファイル一覧取得）。対象: $ARGUMENTS")
   ```

2. 引数の解釈（課題キー → 課題取得、キーワード → 検索、ファイル URL → ファイル一覧 等）はスキル側の操作種別判定に委ねる

## 引数が空の場合

ユーザに以下を確認する:

- 対象（課題キー / 課題 URL / ファイル URL / 検索条件）
- 取得したい情報（課題本文・コメント・検索結果一覧・共有ファイル一覧）

## 制約

- このコマンドからは書き込み（コメント投稿・メタ情報更新）を行わない。書き込みの依頼が含まれる場合は `/backlog-post`（コメント投稿）/ `/backlog-update`（メタ情報更新）を案内する
- ファイルのダウンロード（バイナリ取得）は行わない。メタデータ（名前・サイズ・更新日時等）の取得のみ対応する
- `git commit` 以降の操作はこのコマンドからは実行しない
