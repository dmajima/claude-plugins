# case-02: 乖離ゼロ（同期済み）

## 入力

```text
ハーネスを更新して
```

前提: ハーネス構築済み。`last_synced_commit` == HEAD。未コミット変更が 2 ファイルある。

## 期待動作

1. Phase 1 の乖離検査で 0 コミットを検出する
2. ドキュメントの更新・分析を行わず「同期済み」を報告して終了する
3. 未コミット変更 2 件の存在を通知し、コミット後の再実行で反映対象になる旨を案内する

## 期待出力

- 「同期済み（最終同期日時・コミット SHA）」の報告
- 未コミット変更の件数通知

## 禁止事項（このケースで起きてはならないこと）

- 乖離ゼロでのドキュメント書き換え・`.sync-state.json` の不要な更新
- 未コミット変更の反映（同期基準はコミット SHA のため対象外）

## 分岐の根拠

procedures.md Phase 1 の検査表「乖離有無」行（`git rev-list --count` が 0 の早期終了パス）。
