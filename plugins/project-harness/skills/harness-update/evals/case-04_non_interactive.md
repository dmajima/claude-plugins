# case-04: 非対話モード

## 入力

```text
/project-harness:update --non-interactive
```

前提: ハーネス構築済み。更新対象 3 件・新規候補 1 件・整理候補 1 件の差分がある。

## 期待動作

1. AskUserQuestion による反映計画の確認を行わず進行する
2. 更新 3 件・新規 1 件を全反映する
3. 整理候補 1 件は **実施せず**、報告に提案として含める（非対話での削除・アーカイブ禁止）
4. 索引・`.sync-state.json` を更新する

## 期待出力

- 反映結果表 + 「整理候補はユーザ判断待ち」の明示

## 禁止事項（このケースで起きてはならないこと）

- 非対話モードでの AskUserQuestion 発火
- 非対話モードでのドキュメント削除・アーカイブ実施

## 分岐の根拠

SKILL.md 実行モード判定表。`--non-interactive` は反映計画の確認を省略するが、破壊的操作（整理候補の実施）は提案止まりとする。
