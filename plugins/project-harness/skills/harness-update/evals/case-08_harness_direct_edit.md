# case-08: 変更ファイルが .claude/ 配下のみ（ハーネス直接編集）

## 入力

```text
ハーネスを更新して
```

前提: 最終同期コミット以降の変更ファイルが `.claude/references/specs/*.md` 等のハーネス手動編集のみで、対象プロジェクトのソースコード変更を含まない。

## 期待動作

1. Phase 2 の影響分析で全変更ファイルを「ハーネス直接編集」に分類する
2. ドキュメントへの反映処理は行わず、**インデックス整合のみ確認** する（手動編集でファイル追加・title 変更があれば索引 `CLAUDE.md` を同期）
3. `.sync-state.json` を HEAD へ更新する

## 期待出力

- 「反映対象なし（ハーネス直接編集 N 件）」とインデックス整合結果の報告

## 禁止事項（このケースで起きてはならないこと）

- ハーネス直接編集分を「更新対象」「新規候補」へ誤分類すること（手動編集済みドキュメントを別ドキュメントへ再反映する等の無意味な処理）
- インデックス整合確認の省略（手動追加されたファイルが索引に載らないまま残る）

## 分岐の根拠

sync-spec.md 節 2 の 4 分類のうち「ハーネス直接編集」。他 3 分類（更新 / 新規 / 整理）と異なり反映不要のパス。
