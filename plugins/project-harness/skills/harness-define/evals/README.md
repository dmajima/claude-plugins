## 実行確認方法

各ケースの「入力」セクションのフレーズで Claude Code を起動し、「期待動作」「期待出力」と一致することを目視確認する。
本スキルはユーザとの対話・提供資料を入力とする AI 主導スキルであり、実行結果がヒアリング内容に依存するため、自動実行スクリプト（demo.sh）は適用外とし、目視確認を基本とする。
生成物の機械検証は `${CLAUDE_PLUGIN_ROOT}/references/scripts/validate/validate_harness.sh` が担う。

## ケース追加ルール

新しい分岐ロジックを追加した時は、対応するケースファイル（`case-{2 桁番号}_{snake_case 名}.md`）を必ず追加し、本一覧表を同期する。各ケースには「分岐の根拠」「関連ケース」セクションを含める。
