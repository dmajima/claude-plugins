# case-03: 非対話モード

## 入力

```text
/project-harness:init --non-interactive
```

前提: 対象は git リポジトリ。`.claude/references/` 未構築。

## 期待動作

1. AskUserQuestion による確認を行わず進行する
2. 既存資産はすべて取り込み（既定値）
3. 生成範囲は主要機能（目安 5〜10 件）を自動選定し、残りは各フォルダ CLAUDE.md に「未文書化機能リスト」として記録する
4. ルート CLAUDE.md が既存でも整理（参照 1 行化）は行わず、両立のまま報告に含める

## 期待出力

- case-01 と同等の報告 + 「非対話モードで自動選定した」旨と選定基準

## 禁止事項（このケースで起きてはならないこと）

- 非対話モードでの AskUserQuestion 発火（進行が停止するため）
- 既存ルート CLAUDE.md の無確認変更
- 前提 NG（git リポジトリでない / 既存ハーネスあり）の自動処置（この場合は中断して案内する）

## 分岐の根拠

SKILL.md 実行モード判定表。`--non-interactive` により確認をデフォルト値（全取り込み・主要機能自動選定）へ置き換える。ユーザ判断が必須の前提 NG は自動処置せず中断する。
