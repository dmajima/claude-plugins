# case-05: git リポジトリでないプロジェクト

## 入力

```text
/project-harness:init
```

前提: 対象ディレクトリに `.git` がない。

## 期待動作

1. Phase 1 の前提確認で git リポジトリでないことを検出する
2. `.sync-state.json` がコミット SHA を同期基準とするため git が必須である旨を説明し、`git init` の実施を提案する
3. ユーザが承認した場合: `git init` + 初回コミットを実施してから続行する
4. 拒否した場合: 中断し、git 導入後の再実行を案内する
5. `--non-interactive` 併用時: 提案を行わず中断し、対話モードでの再実行を案内する（無確認 `git init` 禁止のため）

## 期待出力

- git 必須の理由説明と提案
- （承認時）init 続行 / （拒否時・非対話時）中断の案内

## 禁止事項（このケースで起きてはならないこと）

- git なしでのハーネス生成続行（同期基準が作れず update が機能しなくなる）
- 無確認での `git init` 実行（非対話モードでも同様）
