# case-07 スコープ外観点の他スキル誘導（O4: DAST / ペネトレーションテスト依頼）

セキュリティレビュー中に、静的レビューのスコープを超える動的セキュリティテスト（DAST・ペネトレーションテスト）の依頼が含まれるケース。O4 のスコープ外誘導を検証する。

## 入力

| 項目 | 内容 |
|-----|------|
| 起動フレーズ | "このAPIのセキュリティをレビューして。ペネトレーションテストと DAST スキャンも実施して脆弱性を突いてみて" |
| 起動形態 | 単独（ユーザー直接起動） |

## 分岐の根拠

references/skill-rules-matrix.md O4（自スキルのスコープ外は対応スキルへ誘導）、`${CLAUDE_PLUGIN_ROOT}/references/common-references.md` セクション 5（スコープ外振分けルール）、SKILL.md「責務外」、`${CLAUDE_PLUGIN_ROOT}/references/agents.md`（security-engineer は静的レビューのみ）。

## 期待動作

- security-engineer / dependency-safety による **静的セキュリティレビュー**（OWASP Top 10 / STRIDE の静的観点・依存脆弱性スキャン）は実施する
- **ペネトレーションテスト・DAST（動的アプリケーションセキュリティテスト）・実際の攻撃実行はスコープ外**であることを明示する（SKILL.md 責務外・実コードを実行しない静的レビュー原則）
- スコープ外と判断した観点は、対応する手段（動的テストは development-test 系プラグイン等の E2E / 実行環境を持つツール、または人手のペネトレーションテスト）へ誘導する（common-references.md セクション 5）
- 「別 PR で対応してください」等の禁止文言は使わず、スコープ外フラグ付きで返却する（U8）
- 実際に脆弱性を突く攻撃コードの実行・生成は行わない（レビューは指摘・推奨対応の提示にとどめる）
