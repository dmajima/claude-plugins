# case-10 投稿順序（インライン → 旧サマリー close → サマリー）

Step 7 の投稿順序規定に従い、インラインコメントを全件投稿後にサマリースレッドを投稿するケース。

## 入力

| 項目 | 内容 |
|-----|------|
| 起動フレーズ | "PR #202 をレビューして"（Azure DevOps、指摘 3 件） |
| モード | 対話 |

## 分岐の根拠

SKILL.md Step 7 投稿順序「1. インラインコメント → 2. 旧サマリー closed → 3. サマリースレッド」。

## 期待動作

- CR-001, CR-002, CR-003 の順にインラインコメントを個別投稿する
- 各インライン投稿後に API レスポンスから thread_id を取得する
- 全インライン投稿完了後に、旧自著サマリースレッドを status=closed に更新する
- サマリースレッド本文に Finding ID リンク（thread_id 使用）を埋め込む
- サマリースレッドを新規スレッドとして最後に投稿する
- サマリーをインラインより先に投稿しない
