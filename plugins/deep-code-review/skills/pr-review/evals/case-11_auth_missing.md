# case-11 認証情報欠落時のユーザー問い合わせ

Step 1.5 で認証情報が確認できない場合、API を呼ばずにユーザーに準備を依頼するケース。

## 入力

| 項目 | 内容 |
|-----|------|
| 起動フレーズ | "PR #303 をレビューして"（GitHub、gh auth status 失敗） |
| モード | 対話 |

## 分岐の根拠

SKILL.md Step 1.5「いずれも確認できない場合: API を呼ばずに AskUserQuestion でユーザーに準備を依頼し、整うまで Step 1 以降には進まない」。

## 期待動作

- gh auth status が失敗し、GH_TOKEN / GITHUB_TOKEN 環境変数もない
- API リクエストを発行しない（誤った資格情報の外部送信を防ぐ）
- AskUserQuestion でユーザーに認証準備を依頼する
- 資格情報の値そのものを表示しない（マスクする）
- 認証が整った後に Step 1 から再開する

## 関連ケース

- case-01: GitHub PR（認証正常）
