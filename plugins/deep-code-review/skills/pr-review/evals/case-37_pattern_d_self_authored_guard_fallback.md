# case-37 Pattern D の自著限定ガード（H2 フォールバックが他者起票に一致 → スキップ）（P24）

スコープ外了承（Pattern D）でマッピングが欠落し、Step 1.5 の H2 見出しフォールバックが **他者（人間レビュアー）起票スレッド**に一致した場合に、自著限定ガードにより reply・status 更新を行わずスキップして手動確認推奨として報告する分岐。H2 フォールバックがボット起票（自著）に一致して続行する case-36 と対になり、Pattern D の自著ガードを検証する。

## 入力

| 項目 | 内容 |
|-----|------|
| 起動フレーズ | "CR-005 はスコープ外として了承、スレッド閉じて"（pr-review を `ack-scope-out=CR-005` 相当で起動） |
| モード | 対話 |
| PR / マッピング状態 | `finding-thread-map.json` に CR-005 のマッピングが欠落。PR の現在スレッドに `## [CR-005] ...` の H2 見出しを持つスレッドが 1 件存在するが、そのスレッドは **人間レビュアー起票**（認証ボットユーザーと不一致） |

## 分岐の根拠

skills/pr-review/references/comment-status-policy.md セクション0.5（Pattern D 安全方針: 自著限定 適用する・他者起票は触らない）・セクション0.2（自著スレッドのみ・uniqueName / login 照合・大文字小文字無視・空文字ガード・displayName 禁止）、skills/pr-review/references/scope-out-pattern-d.md セクション2 + Step 1.5（マッピング欠落時の H2 見出しフォールバック）、`${CLAUDE_SKILL_DIR}/references/author-identity.md`、skill-rules-matrix.md P23 / P24。

## 期待動作

- 起動: `ack-scope-out=CR-005` により通常レビューフロー（Step 1〜8）をスキップし Pattern D フローのみ実行する（scope-out-pattern-d.md セクション2）
- Step 1: `finding-thread-map.json` から CR-005 の thread_id 解決を試みる → マッピング欠落
- Step 1.5: PR の現在スレッド一覧を取得し、各スレッド本文冒頭の `## [CR-NNN]` H2 見出し形式で CR-005 を探索 → `## [CR-005] ...` を持つスレッドが 1 件一致する
- **自著限定ガード（セクション0.5 / 0.2）**: 一致スレッドの起票者を author-identity.md の一意識別子（uniqueName / login）で判定 → 認証ボットユーザーと **不一致（人間レビュアー起票）** と判定する
- 判定結果: 他者起票のため Pattern D の reply 投稿・status 更新を **行わない**。当該 CR-005 を「自著でないため未処理（手動確認推奨）」として完了報告に含める（セクション0.2「未解決のまま、手動確認推奨」・セクション0.5「他者起票は触らない」）
- 自著判定は大文字小文字を無視し、空文字ガードを行う。`displayName` では比較しない（author-identity.md・なりすまし防止）
- 他のスレッドに副作用を及ぼさず、最終状態検証（P26）と完了報告（P27）に処理 0 件・スキップ（他者起票）1 件を明記する
- （以下は検出してはならない誤り）
    - H2 見出しが一致したことだけを根拠に、起票者を確認せず他者起票スレッドへ了承 reply + status 更新する（セクション0.5 自著限定違反・他者スレッドの誤解消）
    - `displayName` で自著判定する（表示名は変更・なりすまし可能・セクション0.2 禁止）
    - 他者起票で処理しなかった事実を完了報告に残さず黙ってスキップする
