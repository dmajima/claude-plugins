# case-26 コメント投稿不要明示時の投稿スキップ（P5 スキップパス）

ユーザーが「PR へのコメント投稿は不要」と明示した場合に、既定の投稿必須動作をスキップし、レビュー結果をユーザーへ直接報告するケース。既定で投稿必須の case-01 に対する対の分岐。

## 入力

| 項目 | 内容 |
|-----|------|
| 起動フレーズ | "PR #123 をレビューして。ただし PR へのコメント投稿は不要、結果だけ教えて" |
| モード | 対話 |

## 分岐の根拠

references/skill-rules-matrix.md P5「PR コメント投稿は既定で必須 /『コメント投稿不要』明示時のみスキップ」、SKILL.md 権限ポリシー「PR コメント投稿は必須（既定動作）: 別途指示されない限り PR への結果投稿（サマリースレッド + インラインコメント）は必須」。本ケースはユーザーが投稿不要を明示した否定パスで、既定の投稿必須（case-01 等）に対する対の分岐。

## 期待動作

- ユーザーが「コメント投稿不要」を明示したため、既定の投稿必須動作をスキップすると判定する（P5）
- レビュー自体（ホスト判定 → 差分取得 → code-review オーケストレーターへの委譲）は通常どおり実施する
- code-review の統合結果を PR に投稿せず、レビュー結果をユーザーへ直接報告する
- インラインコメント投稿・サマリースレッド投稿・旧サマリー closed 化のいずれも実行しない
- connector の投稿系（`*-post`）委譲を行わない（読み取り系のみ使用）
- reply 投稿を伴う auto-resolve（status 変更）も行わない（PR への書き込みを伴うため）
- 完了報告に「コメント投稿不要指示によりスキップ」した旨と、PR 外書き込みなしを明記する（P19）
