# case-20 短い PR レビュー依頼フレーズでの起動（トリガー検証）

PR 識別子を含まない短い日本語フレーズで pr-review が起動し、対象 PR の特定を経てレビューフローに進むことを検証するトリガーケース。識別子が明示される case-18 / case-19 と異なり、識別子解決ステップが加わる。

## 入力

| 項目 | 内容 |
|-----|------|
| 起動フレーズ | "PRをレビューして" |
| モード | 対話 |

## 分岐の根拠

SKILL.md description / トリガー条件のトリガーフレーズに準じた短い依頼で pr-review が起動する。SKILL.md「前提」は PR 識別子（URL または ID）の提供を要するが、本フレーズには識別子が含まれないため、対象 PR の特定（現在ブランチに紐づく PR の解決、または AskUserQuestion での確認）を要する分岐。識別子が明示される case-18 / case-19 と異なり、識別子解決ステップが加わる。

## 期待動作

- 「PRをレビューして」で code-review:pr-review スキルが起動する（トリガー条件）
- 起動フレーズに PR 識別子が含まれないため、対象 PR を特定する（現在ブランチに紐づく PR の解決、または不明時は AskUserQuestion で確認。SKILL.md「前提」）
- 識別子の特定後、通常フロー（ホスト判定 → 差分取得 → code-review 委譲）に進む
- Step 7: レビュー結果を PR にコメント（インラインコメント + サマリースレッド）として投稿する（既定で投稿必須・P5）
