# case-33 P9 コード引用範囲の規範遵守（引用範囲ズレ・言語識別子欠落の検出と修正後再投稿）

インラインコメントに添えるコード引用が P9 の 2 要件（(a) コードフェンス + 言語識別子明記、(b) 引用範囲と `start_line`/`line` の完全一致）を満たさない**失敗パス**を検証する。引用範囲が指摘箇所の行範囲とズレている／言語識別子が欠落しているドラフトを検出し、指摘箇所に一致するよう修正してから再投稿する分岐を見る。コードフェンスの有無のみを見る SANITIZE チェックとは別レイヤの規範であることを区別する。

| モード | 対話（PR コメント投稿を伴う） |

## 期待動作

- 投稿前チェックで当該インライン本文が P9 を満たさないことを検出する（checklist B 節 P9・output-format.md セクション 2.5）
- (a) コードフェンスに言語識別子が欠落しているため、対象言語（例: `csharp`）を明記した ` ```csharp ` に修正する（output-format.md セクション 2.5「言語識別子明記」）
- (b) 引用スニペットの範囲が指摘箇所からズレているため、引用範囲を指摘箇所の `start_line`〜`end_line` と一致するよう修正する。過大引用を避け前後 2〜3 行のコンテキストに留める（output-format.md セクション 2.5「範囲一致」「過大引用禁止」）
