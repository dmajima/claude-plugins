# code-review-architecture スキル

コード変更を **アーキテクチャ観点・データ層観点**（システム構造・技術選定・DB スキーマ）からレビューする観点別スキル。
内部で architect / dba の 2 エージェントを並列起動し、結果を観点別中間レポートとして返却する
（DB 変更がない場合は dba を内部で省略）。

## このドキュメントについて

このファイルは **人間向けのリファレンス** です。Claude Code がスキル動作中に参照することはありません。
スキルが実行時に参照するのは `SKILL.md` と `references/` 配下です。

## 評価観点

| 観点 | 担当エージェント | 責務 |
|------|----------------|------|
| アーキテクチャ全体整合性 | architect | システム設計・技術選定・拡張性・技術的負債・コンポーネント境界・依存方向 |
| データ層 | dba | DB スキーマ・SQL 最適化・マイグレーション安全性・インデックス・データ整合性 |

エージェントの起動条件:

| エージェント | 起動条件 |
|------------|---------|
| architect | 常に起動 |
| dba | SQL / DB スキーマ / マイグレーション変更が一切ない場合のみ内部で省略 |

本スキル自体を呼ぶか否かの判断はオーケストレーター側の責務
（アーキテクチャに影響しない単純変更のみ かつ DB 変更なしの場合に省略される）。

## 使い方

### トリガーフレーズ例

```
アーキテクチャ観点でレビューして
設計影響を確認して
DB スキーマ変更 / マイグレーションをレビューして
```

大規模リファクタリング・コンポーネント境界の変更時に特に有効。

### 起動経路

| 経路 | 説明 |
|------|------|
| code-review オーケストレーター経由 | 標準モードの観点別スキルとして Skill ツール経由で委譲される（簡易モードでは実行されない） |
| 単独起動 | 上記トリガーフレーズで本スキルのみを直接実行する |

## 出力

`SKILL.md` の「出力フォーマット」に従い、設計上の問題・技術的負債リスク・コンポーネント境界の指摘と、
DB 変更あり時はスキーマ変更の安全性評価・マイグレーション戦略・最適化提案を **観点別中間レポート** として返却する。
統合サマリの最終フォーマット・Verdict 判定はオーケストレーター（`code-review`）の責務。

## ファイル構成

```
plugins/deep-code-review/skills/code-review-architecture/
├── SKILL.md                              # Claude が実行時に読むスキル定義
├── README.md                             # 本ファイル（人間向け）
├── evals/                                # 動作分岐検証ケース（case-01〜09 + README）
└── references/
    └── checklist.md                      # 中間レポート返却前の達成チェックリスト
```

## スコープ外

- レビュー対象ソースコードの変更（指摘提示のみ）
- 実装品質・テスト・セキュリティ等の他観点（対応する観点別スキルが担当）
- 統合サマリ生成・Verdict 判定（code-review オーケストレーターが担当）
