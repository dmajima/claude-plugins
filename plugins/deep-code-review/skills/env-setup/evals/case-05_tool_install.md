## 分岐の根拠

SKILL.md description / トリガー条件「『必要なツールをインストールして』と言われた場合」に合致し env-setup が起動、「インストールして」明示によりインストールモード（SKILL.md 実行モード判定 2）へルーティングされる。winget 最優先（E4 優先順位 1）と管理者権限の自動昇格禁止（E3）を適用する。AskUserQuestion 承認の詳細は case-02、優先順位の適用順の網羅は case-09 が担う。

## 期待動作

- 「インストールして環境構築して」で env-setup スキルが起動する（トリガー条件）
- 「インストールして」明示によりインストールモードと判定する（実行モード判定 2）
- インストール前に AskUserQuestion で承認を取得する（E2）
- gh / az は winget を最優先で使用する（`winget install --id GitHub.cli ...` / `--id Microsoft.AzureCLI ...`。E4 優先順位 1）
- 管理者権限が必要な場合は自動昇格せず、管理者 PowerShell での手動実行コマンドを案内する（E3）
- インストール後に `gh --version` / `az --version` で再確認して結果を報告する（実行フロー 6）
