# case-10 委譲・verify 完全非対話（存在確認のみ・AskUserQuestion 不発火・構造化結果返却）（E1）

pr-review が必要ツールの存在確認のみを env-setup へ委譲するケース。操作 `verify` はインストールを伴わないため AskUserQuestion（E2 承認）を一切発火せず、構造化結果のみを呼び出し元へ返す完全非対話パス。インストールを伴い承認を対話で挟む case-03（委譲・install）に対する、インストールなし完全非対話の対。

## 入力

| 項目 | 内容 |
|-----|------|
| 委譲 args | 操作 `verify` / 対象ツール `gh,az,azure-devops` / 呼び出し元 `pr-review` |
| モード | 委譲呼び出し（完全非対話・AskUserQuestion 不発火） |

## 分岐の根拠

references/skill-rules-matrix.md E1「確認モード既定（明示指示なしの場合は存在確認のみ）」、SKILL.md「実行モード判定」冒頭（「他スキル（pr-review / code-review-* 等）からの委譲呼び出し時は、引数（verify / install・対象ツール）に従い非対話で実行する」）・「実行モード判定」1（確認モード（既定）：存在確認のみを行う）・「入力（呼び出し時の引数）」表（操作 `verify` / `install`）。操作が `verify`（存在確認のみ）でインストールを伴わないため、E2（インストール実行前の AskUserQuestion 承認）は発火しない。インストールを伴いユーザー承認を対話で挟む case-03（委譲・install）に対する、インストールなし完全非対話パス。

## 期待動作

- 委譲 args から操作 `verify`・対象 3 ツール・呼び出し元 `pr-review` を解釈する（SKILL.md「実行フロー」1）
- 確認モード（既定）として `where gh az`（azure-devops 拡張は `az devops --help`）等で **存在確認のみ** を行い、winget / `az extension add` 等のインストールコマンドを一切実行しない（E1）
- verify（確認のみ）はインストールを伴わないため、AskUserQuestion によるインストール承認（E2）を発火しない（完全非対話で進行する）
- 委譲呼び出しのため、不足ツールがあってもユーザーへのインストール可否問い合わせ（対話）を行わず、不足を構造化結果として報告するにとどめる（SKILL.md「実行モード判定」冒頭の非対話委譲）
- 管理者昇格・パッケージ導入コマンドの自動実行も行わない（E3）
- 結果は「## env-setup 結果」フォーマットで、インストール済み（バージョン付き）と未インストールのツールを構造化して呼び出し元（pr-review）に返す（SKILL.md「出力フォーマット」、checklist C-Auto-1）
- `gh auth login` / `az login` 等の認証はスコープ外として扱い、認証情報の値を結果に含めない（SKILL.md「責務外」、checklist C-Auto-3）
