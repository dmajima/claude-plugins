# env-setup evals

本ディレクトリは `env-setup` スキルの **AI の動作分岐検証ケース集**。
1 ケース 1 ファイルで、スキルの規範（SKILL.md / references/）に基づく分岐ごとに期待動作を定義する。

## ケース一覧

| case | ファイル名 | 検証する分岐 | モード |
|------|-----------|------------|--------|
| 01 | case-01_verify_mode_default.md | 確認モード（既定・存在確認のみ・インストール不実行） | 対話 |
| 02 | case-02_install_mode_user_approval.md | インストールモード（明示指示・AskUserQuestion 承認・winget 最優先・自動昇格禁止） | 対話 |
| 03 | case-03_delegated_install_from_pr_review.md | 他スキル委譲（カテゴリ A 一次責務・ツール固有サブコマンド・前提順序） | 委譲（承認は対話） |
| 04 | case-04_tool_verify.md | ツール確認フレーズでの起動（トリガー検証・E1 確認モード） | 対話 |
| 05 | case-05_tool_install.md | ツールインストール依頼での起動（トリガー検証・winget 最優先） | 対話 |

## ケースファイルの構成

各ケースファイルは以下のセクションで構成する。

| セクション | 内容 |
|-----------|------|
| 入力 | 起動フレーズまたは委譲 args / 対話・非対話モード |
| 分岐の根拠 | SKILL.md / references のどの規範に基づく分岐か（ファイル名・セクションを明記） |
| 期待動作 | 検証可能な期待動作の箇条書き |
| 関連ケース | 対になる分岐・前提となるケースへの参照 |

## 起動形態の軸について

本スキルの evals は「確認モード（E1・存在確認のみ）」と「インストールモード（E2 承認を伴う）」の 2 軸を主軸に分岐を検証する。この 2 軸が対話 / 非対話の別を規定する: 確認モードはインストールを伴わないため AskUserQuestion（E2 承認）を発火せず、特に他スキルからの委譲による `verify` は完全非対話で構造化結果を返す（case-10）。一方インストールモードは実行前に必ず AskUserQuestion で承認を挟むため対話であり、委譲経由（`install`）でもユーザー承認は省略しない（case-03）。ユーザー直接起動時の確認モード（case-01）も存在確認のみで完結し、インストール可否の問い合わせはツール不足を検知した場合にのみ発生する。
