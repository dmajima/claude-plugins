# case-04 ツール確認フレーズでの起動（トリガー検証）

「揃っているか確認して」の依頼で env-setup が起動し、インストール明示がないため確認モード（既定・E1）にルーティングされることを検証するトリガーケース。確認モードの詳細動作は case-01 が担う。

## 入力

| 項目 | 内容 |
|-----|------|
| 起動フレーズ | "コードレビューに必要なツールが揃っているか確認して" |
| モード | 対話 |

## 分岐の根拠

SKILL.md description / トリガー条件「『環境構築して』『必要なツールをインストールして』と言われた場合」に準じた確認依頼で env-setup が起動する。「確認して」でインストールの明示がないため、references/skill-rules-matrix.md E1（確認モード既定）にルーティングされる。確認モードの詳細動作は case-01 が担う。

## 期待動作

- 「確認して」の依頼で env-setup スキルが起動する（トリガー条件）
- インストールの明示がないため確認モード（既定・E1）と判定する
- 管理対象ツール（gh / az / node / dotnet 等）の存在を `where <tool>` で確認する（SKILL.md 実行フロー 2）
- 不足ツールがあれば一覧をユーザーに提示する（実行フロー 3）
- インストールは実行せず、インストール可否の確認に留める（E1・E2）
