# case-04 自然言語フレーズでのトリガー起動（対話モード）

「コードレビューして」「コードレビューをお願いします」等の短い/汎用的な日本語フレーズで、スコープ引数なしにオーケストレーターが起動するケース。トリガー認識と既定スコープの確定を検証する。

## 入力

| 項目 | 内容 |
|-----|------|
| 起動フレーズ | "コードレビューをお願いします" / "コードをレビューして"（スコープ引数なし） |
| モード | 対話 |

## 分岐の根拠

SKILL.md「トリガー条件」（「コードレビューして」「差分をレビューして」等）、`${CLAUDE_SKILL_DIR}/references/flow/scope-detection.md`（スコープ未指定時はカレントブランチ差分を既定対象・比較ブランチ `origin/develop` → `main` → `master` 自動判定）、`${CLAUDE_SKILL_DIR}/references/flow/mode-selection.md`（対話モードで AskUserQuestion によるモード選択）。

## 期待動作

- `code-review` オーケストレータースキルが起動する（トリガー認識）
- スコープ引数がないため、Step 1 でカレントブランチの差分を既定レビュー対象とし、比較ブランチを自動判定する（scope-detection.md）
- Step 0 で AskUserQuestion により標準/簡易モードを確認する（対話モード）
- Step 2 以降の通常フロー（言語検出・規約読込・観点別スキル並列起動・統合サマリ）を実行する
- PR 識別子を含まないため `pr-review` ではなく `code-review` が起点となる（C12）
