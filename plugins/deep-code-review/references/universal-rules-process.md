## U7. PR 外への影響禁止（MANDATORY）

### 規範

レビュー実行中、**PR 自体への書き込み（コメント・スレッド・status）以外は禁止**。
具体的には Work Item / Issue / Boards カード / 別 PR / 別ブランチ / Wiki / 通知システム / リポジトリ設定への書き込みを行わない。
ユーザー明示要求時のみ例外として実行可能（事前承認・ロールバック・完了報告での明記が必須）。

### 達成基準

```
[ ] Work Item / Issue / Boards カード等を作成していない
[ ] 既存 Work Item / Issue のステータス・assignee・ラベル等を変更していない
[ ] 別ブランチ / 別 PR を作成していない
[ ] Slack / Teams / メール等の通知を送信していない
[ ] リポジトリ設定（ブランチ保護・Webhook 等）を変更していない
[ ] Wiki / Pages / 外部システムへ書き込みしていない
[ ] ユーザー明示要求で例外実行した場合、対象・操作内容を完了報告に明記している
```

### 詳細

## U8. 別 PR 推奨の禁止（MANDATORY）

### 規範

レビュー指摘・改善提案・所見の本文に「別 PR で対応してください」「別チケット化してください」「Issue を作成してください」等の表現を入れない。
本 PR スコープ外と判断した指摘は **「スコープ外指摘」セクション** に分離して記載する。
別チケット化・別 PR 起票の判断は PR 作成者・PdM が行う（レビュアーは強制しない）。

### 達成基準

```
[ ] 出力本文に「別 PR で対応してください」「別途 PR を起票」等の文言が含まれていない
[ ] 本 PR スコープ外の指摘を「スコープ外指摘」セクションに分離している
[ ] スコープ外指摘に判断理由（PR 目的・仕様書・既存実装の課題のいずれか）を明記している
[ ] スコープ外指摘で期限を強制していない
```

### 詳細

詳細・OK/NG 例は `${CLAUDE_PLUGIN_ROOT}/references/scope-out-policy.md` セクション 1, 3, 5 を参照。

## U9. エージェント並列起動（MANDATORY）

### 規範

独立した観点でレビューするエージェントは **1 メッセージ内で複数の Agent ツールコール** として並列発行する（Independent 型）。
前段サブエージェント結果が必要な場合のみ逐次実行する。

### 達成基準

```
[ ] 観点別スキルが内部で並列起動可能なエージェントを 1 メッセージで並列起動している
[ ] オーケストレーターが観点別スキルを 1 メッセージで並列起動している
[ ] 結果統合をメインで行い、エージェント間の直接通信は行っていない（Agent Teams を除く）
```

### 詳細

`${CLAUDE_PLUGIN_ROOT}/references/agents.md` セクション 3 を参照。

## U10. エージェント共通指示の付与（MANDATORY）

### 規範

各エージェントのプロンプトには末尾に共通指示（プロジェクト規約参照・指摘必須項目・スコープ判定・別 PR 推奨禁止）を必ず含める。

### 達成基準

```
[ ] プロジェクト規約参照指示（CLAUDE.md / .claude/rules/ / CONTRIBUTING.md / .editorconfig）を含めている
[ ] レビュー範囲の制約（test-runner 以外は実行しない・全件報告・重複避ける）を含めている
[ ] 別 PR / 別チケット推奨の禁止 + PR 外への影響禁止を含めている
[ ] 指摘ごとの必須項目（致命度・担当エージェント・指摘箇所・該当コード・指摘内容・求める修正・理由・スコープ判定）を含めている
```

### 詳細

`${CLAUDE_PLUGIN_ROOT}/references/agents.md` セクション 4.4 を参照。

## U11. 重要度付与・重複統合の規範（MANDATORY）

### 規範

- 評価語マッピング（Critical / High / Medium / Low）を統一基準で適用する
- 同一ファイル・同一行・同一テーマの指摘は 1 件に統合し、最も重い重要度を採用する
- 衝突する評価は **より厳しい側** を採用する

### 達成基準

```
[ ] 重要度表記が Critical / High / Medium / Low に統一されている
[ ] 同一指摘の重複が統合されている
[ ] 衝突時に厳しい側を採用した記録が観点間の見解の差異セクションに残っている
```

### 詳細

`${CLAUDE_PLUGIN_ROOT}/references/severity-ranking.md` を参照。
