`convert-pptx` スキルを呼び出して Markdown を PowerPoint (PPTX) に変換してください。

引数: $ARGUMENTS

## 実行手順

1. **引数の解釈**
   - 第1引数: 入力 Markdown ファイルパス（必須）
   - 第2引数: 出力 PPTX ファイルパス（省略時はセッションフォルダ直下に `<元ファイル名>.pptx`）
2. **オプション**（任意・指定があればそのまま渡す）

   | オプション | 内容 |
   |-----------|------|
   | `--title <タイトル>` | タイトルスライドの主題 |
   | `--subtitle <副題>` | タイトルスライドの副題 |
   | `--aspect <比率>` | `16:9` または `4:3`（既定 `16:9`） |
   | `--theme <テーマ>` | `default`（Wiki スタイル）または `executive`（経営者向けプレゼン。ネイビー×ゴールド・フッター付き） |
   | `--primary-color <色>` | タイトル帯・見出しの基調色の上書き（既定はテーマの基調色） |
   | `--max-body-chars <数>` | 1 スライド当たりの本文最大文字数（既定 `2400`） |

   「経営者向け」「役員向け」等の依頼では `--theme executive` を指定する。

3. **Skill ツール経由で実行**

   ```
   Skill(skill: "convert-pptx", args: "<入力MD> <出力PPTX> [オプション...]")
   ```

4. 完了後、出力ファイルの絶対パスをユーザーに報告する

## スライド分割規則

| Markdown | 出力スライド |
|---------|-------------|
| 最初の `# タイトル` | タイトルスライド（1枚目） |
| 各 `## セクション` | 新規スライドの先頭 |
| `### / #### / ...` | 同一スライド内の小見出し |
| H2 がない場合 | 全文を 1 枚の本文スライドに配置 |

## 注意

- インターネット接続が必要（mermaid.ink API による mermaid → PNG 変換）
- 1 スライドを超える長さの本文は自動で継続スライドに分割される
