# テーマの対話選択ルール

`convert-pptx` スキル実行時のデザインテーマ選択の詳細ルール。
テーマの配置場所・命名の共通規約は [`../../../references/design-locations.md`](../../../references/design-locations.md) を参照。

## テーマの列挙

スキル実行前に以下 3 箇所の `.json` ファイルを合算して確認する。

| 順序 | 場所 | 由来表示 |
|-----|------|---------|
| 1 | `${CLAUDE_SKILL_DIR}/assets/pptx-themes/` | スキル |
| 2 | `${CLAUDE_PLUGIN_ROOT}/assets/pptx-themes/` | プラグイン共通 |
| 3 | ローカルデザインディレクトリ `<designs>/pptx-themes/`（`design-locations.md` 節 3: リポジトリ内なら `<repo_root>/.claude/.local/plugins/convert-doc/designs/`、無ければ `~/.claude/.local/plugins/convert-doc/designs/`） | ローカルデザイン |

- 同名ファイルは **スキル > プラグイン共通 > ローカルデザイン** の順で優先（下位は選択肢から除外）
- **デフォルトデザインはテーマファイルとしては存在しない**（`convert_pptx.py` 内蔵値が SSOT）。選択肢には常に「デフォルト」を先頭に含める

## 選択の分岐

| テーマファイル数 | 動作 |
|---------------|------|
| 0 | 選択 UI を出さずデフォルトデザインで変換する |
| 1〜2 | `AskUserQuestion` で「デフォルト + 各テーマ」から選択させる |
| 3 以上 | `AskUserQuestion` の options 上限（4 件・「Other」自動付与のため実質 3 件）を超えるため、テキストベースの選択に切り替える |

## 呼び出し方針（AskUserQuestion）

- `question`: `"適用するデザインテーマを選択してください。"`
- `header`: `"テーマ"`
- `multiSelect`: `false`（1つだけ選択）
- `options`:
  - 先頭: `{ label: "デフォルト", description: "内蔵デフォルトデザイン（ネイビー基調）を使用" }`
  - 以降: 検出した `.json` を `{ label: ファイル名（拡張子なし）, description: "<由来> の <ファイル名> を使用" }` で列挙

## 回答の処理

- 「デフォルト」が選択された場合は `--theme` を渡さない
- テーマが選択された場合は、そのファイルの **絶対パス** を `--theme "<絶対パス>"` として渡す
- 「Other」（カスタム指示）が入力された場合は、入力内容を指示として解釈して処理する
- **回答受け取り後、確認なしでそのまま処理を続行する**

## 非対話時の動作

- 別スキルからの `Skill(...)` 呼び出しなど対話が難しい場合は、選択 UI を出さず以下を適用する
  - 呼び出し引数に `--theme` があればそれを使用
  - なければデフォルトデザイン
- ユーザーがテーマ名を明示した場合（例: 「ocean-blue テーマで変換して」）は、列挙結果から名前一致するテーマを解決して `--theme` に渡す（一致がなければ列挙結果を提示して確認）

## `--primary-color` との併用

`--primary-color` はテーマの `primary` より優先される（テーマの他の色はそのまま）。
ユーザーが「テーマ X で、基調色だけ #123456」のような依頼をした場合は両方を渡す。
