# Case 14: ローカル画像のパストラバーサル拒否

## 入力

- 入力 MD に `base_dir`（入力 MD の親ディレクトリ）の外を指すローカル画像参照が含まれる:

  ```markdown
  # 資料

  ## セクション

  ![leak](../../../etc/passwd)
  ```

## 期待動作

1. `_load_image_bytes` がパスを解決し、`_is_within(base_dir, candidate)` の検証で `base_dir` 外と判定する
2. 画像バイトを読み込まない（`None` を返す）
3. スライドには `[画像が見つかりません: leak]` のプレースホルダテキストが配置される
4. 変換自体は継続し、正常終了する（exit 0）

## 期待出力

- `base_dir` 外のファイル内容を一切含まない PPTX
- 該当位置に画像未検出のプレースホルダテキスト

## 分岐の根拠

`SKILL.md`「重要な制約」:
> ローカル画像パスは `base_dir` 配下に解決されることを検証する（パストラバーサル対策）
