# Case 18: テーマ名の明示指定（一致 / 不一致）

## 入力

- テーマ `dark-console.json` が配置済みの状態
- パターン A: 「dark-console テーマでスライドにして」（一致する名前）
- パターン B: 「ocean-green テーマでスライドにして」（存在しない名前）

## 期待動作

- パターン A:
  1. 列挙結果から名前一致するテーマ（`dark-console.json`）を解決する
  2. 選択 UI を出さず、その絶対パスを `--theme` に渡して変換する
- パターン B:
  1. 名前一致するテーマが見つからないことを検出する
  2. **黙ってデフォルトで変換しない**。列挙結果（利用可能なテーマ一覧）を提示してユーザーに確認する

## 期待出力

- パターン A: dark-console が適用された PPTX（追加の確認なし）
- パターン B: 利用可能テーマの一覧提示と選択の確認

## 分岐の根拠

`references/theme-selection.md`「非対話時の動作」:
> ユーザーがテーマ名を明示した場合（例: 「ocean-blue テーマで変換して」）は、列挙結果から名前一致するテーマを解決して `--theme` に渡す（一致がなければ列挙結果を提示して確認）
