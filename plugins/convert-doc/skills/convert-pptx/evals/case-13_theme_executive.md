# Case 13: --theme executive（経営者向けテーマ）

## 入力

- 入力 MD:

  ```markdown
  # 中期経営計画 進捗報告
  第 1 四半期の進捗をまとめる。

  ## 売上は計画比 +4.2% で着地
  本文1

  ## 下期の重点施策
  本文2
  ```

- オプション: `--theme executive`
- または自然言語で「経営者向けに」「役員会向けに」等の依頼

## 期待動作

1. タイトルスライドが executive 構図（ゴールドルール + ネイビータイトル + 下部のゴールドライン付きネイビー帯）で生成される
2. 各 H2 スライドはネイビー塗り帯ではなく、メッセージファースト構図（ディープネイビー #0B2E59 太字のキーメッセージ + 全幅ヘアライン + 左端ゴールド #B8933E アクセント）で生成される
3. 表紙を除く全スライドの下部にフッター（左: ドキュメントタイトル、右: `N / 総数` のページ番号）が付く
4. H1 直後の段落がタイトルスライドのサブタイトルになる（default テーマと同じ分割規則）

## 期待出力

- 3 枚のスライド構成（タイトル + 2 セクション）
- 2〜3 枚目のフッターに `2 / 3`・`3 / 3` が表示される
- 表ヘッダ・強調色はディープネイビー、アクセント線はシャンパンゴールド
