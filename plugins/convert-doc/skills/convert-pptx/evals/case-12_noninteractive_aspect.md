# Case 12: カスタムモード（4:3 アスペクト比指定・追加確認なし）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "このMarkdownを4:3のスライドにして" |
| モード | カスタム（オプション明示指定） |
| 暗黙オプション | `--aspect 4:3` |

## 期待動作

- convert-pptx スキルが起動する
- 「4:3」の指示から `--aspect 4:3` オプションを適用する
- 入力 MD のパスが特定可能な場合はユーザー確認をスキップする
- スライドサイズを 4:3（25.4cm x 19.05cm）で生成する
- H1 タイトルスライド + H2 セクション別スライド構成は変わらない

## 期待出力

| 出力 | 内容 |
|-----|------|
| 成果物 | 4:3 アスペクト比の PPTX ファイル（セッションフォルダ直下） |
| スライドサイズ | 25.4cm x 19.05cm（4:3） |

## 分岐の根拠

`SKILL.md`「実行モード判定」:
> `--aspect 4:3` / `--primary-color` / `--theme` 等の指定 | カスタム | 指定されたアスペクト比・色・テーマで処理

「4:3」の自然言語指示が `--aspect 4:3` フラグに変換され、デフォルトの 16:9 ではなく 4:3 のスライドサイズ分岐を選択する（別スキルからの `Skill(...)` 呼び出しによる「非対話」モードは [case-17_theme_noninteractive.md](case-17_theme_noninteractive.md) を参照）。
