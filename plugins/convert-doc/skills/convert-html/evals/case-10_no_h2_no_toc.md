# Case 10: H2 が存在しない MD → 目次サイドバーが空

## 入力

- 入力 MD: H2 を含まない
  ```markdown
  # タイトル
  これは段落です。

  本文のみで小見出しを持たない。
  ```

## 期待動作

1. `convert.py` の目次生成ロジックが H2-H6 を検索
2. ヒット 0 件のため、TOC サイドバーには項目が一つも追加されない
3. CSS の表示制御により、TOC コンテナが空でも本文のレイアウトを崩さない

## 期待出力

- 出力 HTML は生成される
- TOC サイドバー（`<nav class="toc">` 等）の中身が空である
- 本文（`<main>` 等）が正常にレンダリングされる

## 分岐の根拠

`convert.py` の目次生成:
- 正規表現で `^## .*` 〜 `^###### .*` を検索
- マッチ 0 件 → `toc_html = ""` または `<nav class="toc"></nav>` を生成
