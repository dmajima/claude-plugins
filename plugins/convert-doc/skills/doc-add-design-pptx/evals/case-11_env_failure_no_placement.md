# Case 11: 環境起因の失敗時は配置に進まない

## 入力

- パターン A: オフライン環境での初回起動（依存パッケージのインストールが失敗）
- パターン B: スキーマ検証は PASS したがサンプル変換（`convert_pptx.py` 実行）が失敗する

## 期待動作

- パターン A: venv 構築（pip install）の失敗を検出し、前提（初回はインターネット接続あり）を
  満たしていないことを原因として報告する。テーマ生成・配置に進まない
- パターン B: サンプル変換の失敗（非 0 exit・エラーメッセージ）を検出し、原因を報告して
  **配置に進まない**。修正可能な原因なら修正して再変換する

## 期待出力

- 失敗状態のまま配置されたテーマが存在しない
- 失敗原因（ネットワーク / 変換エラー）の明確な報告

## 分岐の根拠

`SKILL.md`「前提」:
> 初回起動時はインターネット接続あり（python-pptx 等のパッケージインストール用）

`SKILL.md`「重要な制約」:
> テーマ JSON は必ず `validate_theme.py` の PASS と**サンプル変換の成功**を確認してから配置する
