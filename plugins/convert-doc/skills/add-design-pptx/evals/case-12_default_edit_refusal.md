# Case 12: デフォルトデザイン自体の変更依頼への対応

## 入力

- ユーザー依頼: 「convert_pptx.py のデフォルト色を直接変えて」「内蔵デフォルトデザインを書き換えて」

## 期待動作

1. 本スキルはデフォルトデザイン（`Theme` dataclass の内蔵値）と既存テーマを **変更しない** 制約を伝える
2. 代替案を提示する:
   - 新テーマとして追加し、変換時に選択する（本スキルの通常フロー）
   - デフォルト自体の変更を望む場合はスキル外の直接編集作業（プラグイン開発）になる旨を案内
3. ユーザーが新テーマ追加を選んだ場合は通常フロー（case-01）に進む

## 期待出力

- `convert_pptx.py` および既存テーマ JSON が本スキルの実行によって変更されない

## 分岐の根拠

`SKILL.md`「重要な制約」:
> デフォルトデザインの変更（convert_pptx.py 内蔵値・既存テーマの無断編集）は行わない
