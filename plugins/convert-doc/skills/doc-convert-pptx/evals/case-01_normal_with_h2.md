# Case 01: 標準変換（H2 複数あり）

## 入力

- 入力 MD:

  ```markdown
  # 提案資料
  概要

  ## セクション1
  本文1

  ## セクション2
  本文2
  ```

- オプション: なし（デフォルト）

## 期待動作

1. `# 提案資料` をタイトルスライド（1 枚目）として生成
2. `## セクション1` `## セクション2` をそれぞれ新規スライドとして追加
3. 各 H2 配下の本文を該当スライドのコンテンツ領域に配置
4. 16:9 ワイドスクリーン、ネイビー（#003879）タイトル帯

## 期待出力

- 3 枚のスライド構成（タイトル + 2 セクション）
- 各 H2 がスライド見出し帯に配置
- 本文は読み取り可能なフォントサイズで配置

## 分岐の根拠

`SKILL.md`「スライド分割規則」表:
> 最初の `# タイトル` → タイトルスライド（1 枚目）
> 各 `## セクション` → 新規スライドの先頭
