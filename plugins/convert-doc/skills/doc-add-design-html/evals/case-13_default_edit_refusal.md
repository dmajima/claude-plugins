# Case 13: デフォルトデザイン自体の変更依頼への対応

## 入力

- ユーザー依頼: 「template.css の色を直接変えて」「デフォルトデザインを書き換えて」

## 期待動作

1. 本スキルはデフォルト（`template.css` / `template.html`）と既存デザインを **変更しない** 制約を伝える
2. 代替案を提示する:
   - 新デザインとして追加し、変換時に選択する（本スキルの通常フロー）
   - デフォルト自体の変更を望む場合はスキル外の直接編集作業になる旨を案内
3. ユーザーが新デザイン追加を選んだ場合は通常フロー（case-01）に進む

## 期待出力

- `template.css` / `template.html` が本スキルの実行によって変更されない

## 分岐の根拠

`SKILL.md`「重要な制約」:
> デフォルトの `template.css` / `template.html` および既存デザインを変更しない（既存出力の構造不変を保証）
