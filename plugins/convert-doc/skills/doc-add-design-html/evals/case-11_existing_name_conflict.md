# Case 11: 既存デザイン名との重複

## 入力

- 既存デザイン `warm-paper.css` が配置済みの状態で、同名 `warm-paper` を新デザイン名に指定

## 期待動作

1. 探索順序（skill assets → plugin assets → ローカル designs）の走査で同名の存在を検出する
2. 「別名にする / 上書きする」をユーザーに確認する。**無確認で上書きしない**
3. 上書きが選択された場合のみ、検証 PASS 後に置き換える

## 期待出力

- 既存デザインが無確認で消えない
- 別名選択時は新しい名前で配置される

## 分岐の根拠

`references/design-locations.md` 節 4「配置先の決定」:
> 既存の同名ファイルがある場合は無確認で上書きしない（別名提案 or 上書き確認）
