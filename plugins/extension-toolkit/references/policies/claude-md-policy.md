# CLAUDE.md ポリシー

`references/` ディレクトリに配置する **Claude エージェント向け原則文書** `CLAUDE.md` の要件を定義する。

## 1. 目的と位置づけ

| ファイル | 対象読者 | 目的 | エージェント参照 |
|---------|--------|------|---------------|
| `README.md` | 人間（ユーザー・開発者） | 利用方法・動作例・拡張手順の説明 | **禁止** |
| `CLAUDE.md` | Claude エージェント | 正しく動作するための原則・ナビゲーション | **推奨（最初に読む）** |

`README.md` と `CLAUDE.md` は **相互に参照してはならない**。それぞれ独立した読者に向けて完結する。

## 2. 配置ルール

| 配置場所 | 必須/任意 | 条件 |
|---------|----------|------|
| プラグイン直下 `references/CLAUDE.md` | **必須** | `references/` ディレクトリが存在する場合 |
| スキル直下 `references/CLAUDE.md` | 推奨 | `references/` に 3 ファイル以上ある場合 |
| `references/` サブディレクトリ内 | 任意 | サブディレクトリが独立したドメインを持つ場合 |

## 3. 必須コンテンツ

`CLAUDE.md` は以下の構成で記述する。

### 3.1 目的と範囲（必須）

このディレクトリが何を管理し、どの作業に関連するかを 1-3 行で記述する。

### 3.2 原則（必須）

Claude エージェントが従うべき **最上位の行動原則** を箇条書きで列挙する。

- 原則は 5-10 項目を目安とする
- 「何をすべきか」「何をしてはならないか」を明確に記述する
- 詳細ルールへのポインタを含める（原則の展開先として）

### 3.3 ナビゲーション（必須）

タスク種別に応じて「何を読むべきか」を対応表で示す。

```markdown
| タスク | 参照先 |
|-------|-------|
| 新規スキルを作成する | `policies/conventions-structure.md` → `guides/...` |
| レビューを実施する | `checklists/...` → `policies/...` |
```

### 3.4 禁止事項（任意）

エージェントが陥りやすい誤動作を列挙する（過去の失敗事例に基づく）。

## 4. コンテンツの制約

| 制約 | 内容 |
|-----|------|
| 行数 | 200 行以下（references/ ファイル共通） |
| 詳細ルールの記載 | **禁止**（`CLAUDE.md` は原則とナビゲーションのみ。詳細は分離済みファイルを参照させる） |
| README.md の参照 | **禁止**（`README.md` は人間向けであり、エージェント動作で使用しない） |
| 重複記述 | **禁止**（他ファイルの内容をコピーせず、参照リンクで誘導する） |

## 5. README.md との差異

| 観点 | README.md | CLAUDE.md |
|-----|-----------|-----------|
| 読者 | 人間 | Claude エージェント |
| 文体 | 自然言語の説明文 | 決定的・指示的な箇条書き |
| インストール手順 | 含む | 含まない |
| 動作例 | 含む | 含まない（evals/ が担う） |
| ナビゲーション表 | 概要レベル | タスク駆動型 |
| 原則・制約 | 概要レベル | 具体的・網羅的 |
| 拡張手順 | 含む | 含まない |
