# 重複・マージチェック詳細

新規プラグイン登録時に既存プラグインとの重複可能性を評価し、マージ提案を行う手順。

## 1. チェック対象

新規登録対象プラグインと、`marketplace.json` の `plugins[]` 配列の各既存プラグイン。

## 2. 類似度評価軸

### 2.1 名前類似

| 判定 | 基準 |
|-----|------|
| 高 | レーベンシュタイン距離 < 3、または部分文字列一致 |
| 中 | 共通プレフィックス・サフィックス（`-toolkit`、`code-` 等）あり |
| 低 | 上記以外 |

### 2.2 description 類似

description 内の **主要キーワード** を抽出して比較:

| 判定 | 基準 |
|-----|------|
| 高 | キーワード重複率 50% 以上 |
| 中 | キーワード重複率 25〜50% |
| 低 | 25% 未満 |

### 2.3 機能領域類似

各プラグイン内のスキル・コマンド一覧を比較:

| 判定 | 基準 |
|-----|------|
| 高 | スキル名 / コマンド名が一致または近似 |
| 中 | 提供領域（例: 「コード品質」）が同じ |
| 低 | 領域が異なる |

## 3. 総合判定

| 結果 | 条件 | 推奨動作 |
|-----|------|---------|
| 高重複 | 評価軸のいずれかが「高」 | マージ提案 |
| 中重複 | 評価軸の 2 つ以上が「中」 | 差別化点の確認 |
| 低重複 / 重複なし | 全て「低」 | 新規登録続行 |

## 4. ユーザ提示フォーマット

```text
重複チェック結果:

公開対象: {new-plugin-name}
重複度: {高/中/低}

類似プラグイン候補:
1. {existing-plugin-A} — 類似ポイント: {名前類似 / description 類似 / 機能類似}
2. {existing-plugin-B} — 類似ポイント: {...}

選択肢:
1. 既存プラグイン {existing-plugin-A} へのマージ（plugin-toolkit の追加シナリオへ移行）
2. 新規登録を続行（差別化点を明記）
3. キャンセル

どうしますか？
```

## 5. マージシナリオの引き渡し

「マージ」を選択された場合の引き渡し手順:

1. 新プラグインのスキル/コマンド/エージェントを既存プラグインに追加配置するよう `plugin-toolkit` の追加シナリオを案内
2. 新プラグインのディレクトリを削除（ユーザ確認の上）
3. marketplace.json には変更を加えない（既存エントリのまま）

## 6. 差別化点の明記

「新規登録続行」を選択された場合、新プラグインの description に **差別化点** を明記するようユーザに提案:

```text
差別化点を明記してください:

- {既存プラグイン}: {既存の責務}
- {新プラグイン}: {新たな責務}

両者の違いが明確になるよう description を調整しますか？
```

## 7. キャンセル時

何も変更しないで終了。

## 8. 重複チェックの限界

| 制限 | 内容 |
|-----|------|
| 機械的判定 | 完全ではない。最終判断はユーザ |
| 名前変更後の類似 | 名前が異なるが機能が同じ場合は機能領域類似で検出 |
| description 不備 | 既存プラグインの description が貧弱な場合は検出精度低下 |

このため、重複検出は **参考情報** であり、ユーザの最終判断を尊重する。

## 9. 機能領域抽出の方法

各プラグインの `plugins/{plugin-name}/` 配下を Glob:

| 種別 | 抽出ターゲット |
|-----|--------------|
| スキル | `skills/*/SKILL.md` の `name` + `description` |
| コマンド | `commands/*.md` の `description` |
| エージェント | `agents/*.md` の `description` |
| フック | `hooks/hooks.json` のイベント |

これらを集約して機能領域のキーワードリストとする。

## 10. 比較最適化

`marketplace.json` の `plugins[]` が大量にある場合（10+）、以下で比較効率を上げる:

- 名前類似度を最初に評価し、高/中候補のみで詳細比較
- description のキーワード抽出を事前にキャッシュ
- 機能領域比較は名前/description で類似ありの場合のみ実施
