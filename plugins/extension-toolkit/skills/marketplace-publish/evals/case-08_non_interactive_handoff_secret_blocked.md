# Case 08: 非対話ハンドオフモード + シークレット検出時の fail-closed

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "`my-plugin` を非対話で公開" |
| 引数 | `my-plugin --non-interactive` |
| フラグ | `--non-interactive`（**`--full-auto` なし** = ハンドオフモード）|
| 既存状態 | プラグイン実体内に `.env` ファイルあり |

## 期待動作

### Phase 1: モード判定

`--non-interactive` 検出、`--full-auto` 未指定 → **非対話ハンドオフモード**。
git 操作はユーザに案内、自動実行はしない。

### Phase 2: シークレットスキャン → 検出

[`../references/secret-scan.md`](../references/secret-scan.md) のパターンに従いスキャン。`.env` 検出 → fail-closed。

### Phase 3: 選択肢の提供範囲（非対話モード特例）

[`../references/secret-scan.md`](../references/secret-scan.md) の「非対話・フルオート併用時の特例」に従う:

| モード | 選択肢 1（削除）| 選択肢 2（gitignore）| 選択肢 3（続行）| 選択肢 4（キャンセル）|
|-------|---------------|------------------|-------------|-----------------|
| 対話モード | 提供 | 提供 | 提供（二重確認）| 提供 |
| 非対話 ハンドオフ（本ケース）| 案内のみ（再実行待ち）| 案内のみ（再実行待ち）| **不可（fail-closed）**| 案内のみ |
| 非対話 + フルオート | 案内のみ（再実行待ち）| 案内のみ（再実行待ち）| **不可（fail-closed）**| 案内のみ |

非対話モードでは **選択肢 3（誤検出として続行）を提供しない**（対話確認が成立しないため）。利用者は対話モードで再実行するか、選択肢 1 / 2 の事前準備を済ませてから再実行する。

### Phase 4: 引き渡し（処理停止）

| 項目 | 動作 |
|-----|------|
| `marketplace-toolkit` 委譲 | 行わない |
| git 操作の案内 | 行わない（fail-closed） |
| 終了コード | 1 |

```text
[marketplace-publish] Error: Secret detected in plugin body. Aborting non-interactive mode.

検出ファイル:
- plugins/my-plugin/.env — filename:.env

非対話モードでは「誤検出として続行」を選択できません。以下のいずれかで対応:
1. 該当ファイルを削除/移動して再実行
2. .gitignore に追加して再実行
3. 対話モードで再実行（誤検出と判断する場合は二重確認後に続行可能）
```

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 変更ファイル | なし |
| 標準エラー出力 | シークレット検出 + 解決方法案内 |
| 終了状態 | 失敗（exit 1）|
| ユーザ対話 | 発生しない |

## 分岐の根拠

`--non-interactive` 単独（フルオートなし）+ シークレット検出 → ハンドオフモードでも対話確認が成立しないため、選択肢 3 を不可とし fail-closed する。
case-07（フルオート + シークレット）と同じ fail-closed ポリシーを適用するが、本ケースではフルオートでないため git 操作の自動実行も行わない（そもそも実行段階に到達しない）。
