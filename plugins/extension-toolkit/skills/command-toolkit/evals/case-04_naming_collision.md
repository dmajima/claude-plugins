# Case 04: 命名衝突（既存コマンドファイル）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "新しい `/extension` コマンドを作って" |
| 引数 | `extension` |
| フラグ | なし |
| 既存状態 | `commands/extension.md` がすでに存在 |

## 期待動作

### Phase 1: 命名衝突検出

配置先に同名 `.md` が存在することを検出。

### Phase 2: ユーザ確認

```text
コマンド `/extension` は既に存在します（{所在パス}）。

選択肢:
1. 別名で新規作成（例: `/extension-v2`）
2. 既存コマンド改修として進行（既存改修フローへ切替）
3. 上書き（既存内容を破棄、警告あり）
4. キャンセル

どうしますか？
```

### Phase 3: 選択分岐

| 選択 | 動作 |
|-----|------|
| 1 | 新しい名前を確認後、case-01 / case-02 のフロー |
| 2 | case-03（既存改修）のフロー |
| 3 | バックアップ（`<name>.bak`）を取り、上書き実行 |
| 4 | 何もせず終了 |

### Phase 4: 上書き選択時の追加警告

既存内容の主要セクション（ルーティング表 等）を提示し、本当に破棄してよいか再度確認。

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | 選択により異なる |
| 標準出力 | 衝突検出メッセージ + 選択肢 |
| 終了状態 | 選択により異なる（キャンセル時は成功・何もせず） |

## 分岐の根拠

配置先に同名コマンドファイルが存在 である。
