# Case 01: 新規コマンド作成（対話モード）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "新しい `/test-runner` コマンドを作って" |
| 引数 | `test-runner` |
| フラグ | なし |
| 既存状態 | `test-runner.md` 未存在 |

## 期待動作

### Phase 1: パラメータ確認

ユーザに以下を確認:

- 1 行説明（60 文字以内）
- 配置先（プロジェクト / グローバル / プラグイン）
- 引数仕様
- ルーティング先有無（オーケストレータか単機能か）

### Phase 2: テンプレート展開

`templates/command/command.md` をコピー、プレースホルダ置換。

### Phase 3: 検証 + 引き渡し

- description 60 文字以内
- frontmatter valid
- 配置先パス存在確認

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | `{配置先}/commands/test-runner.md` |
| 標準出力 | 「`/test-runner` コマンドを作成」+ 利用例 |
| 終了状態 | 成功 |

## 分岐の根拠

引数 = コマンド名のみ・対話モード である。
