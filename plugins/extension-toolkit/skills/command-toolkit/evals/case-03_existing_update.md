# Case 03: 既存コマンドの改修

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "`/extension` コマンドに `hook` ルートを追加" |
| 引数 | `extension --add-route "hook:hook-toolkit"` |
| フラグ | なし |
| 既存状態 | `extension.md` 既存 |

## 期待動作

### Phase 1: 既存ファイル読込

`extension.md` を Read してルーティング表を抽出。

### Phase 2: ルート追加

ルーティング表に新行追加（既存行は維持）。

### Phase 3: 検証 + 引き渡し

- 既存内容が破壊されていないこと
- エンコーディング維持

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 変更ファイル | `extension.md`（追記） |
| 標準出力 | 「`/extension` に `hook` ルート追加」+ 変更箇所サマリ |
| 終了状態 | 成功 |

## 分岐の根拠

同名コマンドが既存 + `--add-route` 指定 である。
