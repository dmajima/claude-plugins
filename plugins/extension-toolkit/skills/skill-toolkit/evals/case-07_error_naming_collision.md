# Case 07: エラー系（命名衝突 / 配置先未存在）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "新しいスキル `code-formatter` を作って" |
| 引数 | `code-formatter` |
| フラグ | なし |
| 既存状態 | `code-formatter` スキルがすでに存在 |

## 期待動作

### Phase 1: 命名衝突検出

`code-formatter` の所在を Glob で確認、既存を検出。

### Phase 2: ユーザ確認

```text
スキル `code-formatter` は既に存在します（{所在パス}）。

選択肢:
1. 別名で新規作成（例: `code-formatter-v2`）
2. 既存スキル改修として進行（既存改修フローへ切替）
3. キャンセル

どうしますか？
```

### Phase 3: 選択分岐

| 選択 | 動作 | 状態保全 |
|-----|------|---------|
| 1 | 新しい名前を確認後、case-01 / case-02 のフロー | 既存スキル無傷 |
| 2 | 既存改修フロー（case-03）へ | 既存スキル無傷で改修開始 |
| 3 | 何もせず終了（キャンセル）| **既存スキル完全無傷・新規ファイル一切生成しない** |

### Phase 4: キャンセル選択時の状態保全（選択 3）

選択 3 が選ばれた場合の確認事項:

| 項目 | 動作 |
|-----|------|
| 既存 `skills/code-formatter/` | 一切変更せず（読み取りのみ）|
| 新規ファイル生成 | なし（中途半端な雛形を残さない）|
| `marketplace.json` 等の編集 | なし |
| 標準出力 | 「キャンセルしました。何も変更していません。」|
| 終了状態 | 成功（exit 0、ユーザの意思を尊重したキャンセルは「成功」扱い）|

## 配置先未存在の場合

引数で「プラグイン内配置」を指定したが、対象プラグインが未存在の場合:

```text
プラグイン `{plugin-name}` が存在しません。

選択肢:
1. `plugin-toolkit` で先にプラグイン外形を作成
2. 配置先を別のプラグイン or スタンドアロンに変更
3. キャンセル
```

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | 選択により異なる |
| 標準出力 | 衝突検出 / 配置先不在の警告 + 選択肢 |
| 終了状態 | 選択により異なる（キャンセル時は「成功（何もせず終了）」） |

## 分岐の根拠

このケースが分岐するトリガーは命名衝突の検出 または 配置先プラグイン未存在 である。
