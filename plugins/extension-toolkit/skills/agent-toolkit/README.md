# agent-toolkit (skill)

Claude Code のサブエージェント・エージェントチームを設計・作成するスキル。

## このドキュメントについて

このファイルは **人間向けのリファレンス**。Claude Code がスキル動作中に参照することはない。

## 責務（要約）

エージェント・チームの設計・作成のみ。スキル本体・プラグイン外形等は他スキルが担当。

## 導入手順

### 前提

- Claude Code がインストール済み
- `extension-toolkit` プラグインがインストール済み（[プラグイン README の導入手順](../../README.md) 参照）

### 起動方法

以下のフレーズで自動起動します:

- 「コード品質評価エージェントを作って」
- 「`code-review-team` エージェントチームを編成」

または `/extension agent <対象>` 経由で起動できます（[`/extension` コマンド](../../commands/extension.md)）。

## 利用方法（最小例）

ユーザ:
> コード品質評価エージェント `code-quality-reviewer` を作って

Claude（要約）:
> 評価観点設計 → テンプレート展開 → 既存エージェントとの専門領域整合確認

## トリガー例

- 「コードレビュー用エージェントを作って」
- 「セキュリティ評価チームを編成」
- 「`code-reviewer` エージェントに観点を追加」
