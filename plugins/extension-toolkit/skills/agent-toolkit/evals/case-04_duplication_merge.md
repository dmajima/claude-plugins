# Case 04: 重複検出時の統合提案

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "コードレビューエージェント `code-checker` を作って" |
| 引数 | `code-checker --domain "code-quality"` |
| フラグ | なし |
| 既存状態 | `~/.claude/agents/implementation-engineer.md` がコード品質を担当 |

## 期待動作

### Phase 1: 既存エージェント確認

Glob で既存エージェントを列挙。`implementation-engineer` の description にコード品質関連の記述を検出。

### Phase 2: 重複候補の提示

```text
類似エージェントが見つかりました:

- `implementation-engineer` — コード品質・正確性・パフォーマンス（領域が重複）

選択肢:
1. 既存 `implementation-engineer` への観点追加（重複回避）
2. `code-checker` を新規作成（差別化点を明記）
3. キャンセル
```

### Phase 3: 選択分岐

| 選択 | 動作 |
|-----|------|
| 1 | `implementation-engineer.md` 改修フローへ |
| 2 | 差別化点をユーザに確認後、新規作成 |
| 3 | 何もせず終了（成功・キャンセル扱い） |

### Phase 4: 差別化点の検証（選択 2 の場合）

差別化点が不明確 or 重複度が高い場合は再度警告。

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | 選択により異なる |
| 標準出力 | 重複検出メッセージ + 選択肢 |
| 終了状態 | 選択により異なる |

## 分岐の根拠

新規作成対象が既存エージェントと領域重複 である。
