# Case 06: 命名衝突検出

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "新しいプラグイン `dev-toolkit` を作って" |
| 引数 | `dev-toolkit` |
| フラグ | なし |
| 既存状態 | `plugins/dev-toolkit/` がすでに存在 |

## 期待動作

### Phase 1: 命名衝突検出

`plugins/dev-toolkit/` 存在 + `marketplace.json` の `plugins[]` に `dev-toolkit` あり、を検出。

### Phase 2: ユーザ確認

```text
プラグイン `dev-toolkit` は既に存在します。

選択肢:
1. 別名で新規作成（例: `dev-toolkit-v2`）
2. 既存プラグインへの追加配置として進行（追加対象を指定）
3. キャンセル

どうしますか？
```

### Phase 3: 選択分岐

| 選択 | 動作 |
|-----|------|
| 1 | 新しい名前を確認後、case-01 / case-02 のフロー |
| 2 | 追加対象を確認後、case-03 のフロー |
| 3 | 何もせず終了 |

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | 選択により異なる |
| 標準出力（要約） | 衝突検出メッセージ + 選択肢 |
| 終了状態 | 選択により異なる |

## 分岐の根拠

このケースが分岐するトリガーは命名衝突の検出 である。
