# Case 04: 自動修正モード

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "`code-formatter` をレビューして軽微指摘は自動修正" |
| 引数 | `code-formatter --auto-fix` |
| フラグ | `--auto-fix` |
| 既存状態 | スキル既存、`§` 記号や明確な NG パスが含まれる |

## 期待動作

### Phase 1: 通常レビュー

case-01 と同じ手順でレビュー実施。

### Phase 2: 自動修正の対象選別

| 検出内容 | 自動修正可否 |
|---------|-----------|
| `§` 記号 | 可 → 「セクション」に置換 |
| 明確な NG パス（`C:\Users\...`） | 可 → 削除 or `${CLAUDE_SKILL_DIR}` に置換 |
| プレースホルダ残存 | 不可（置換値判断必要） |
| 構造的問題 | 不可 |
| セキュリティ指摘 | 不可（必ずユーザ確認） |

### Phase 3: 自動修正実施

修正可能な項目のみ自動適用。エンコーディング・改行コード維持。

### Phase 4: 結果報告

| 項目 | 内容 |
|-----|------|
| 自動修正済み | 件数 + 詳細 |
| 手動対応必要 | 件数 + 詳細 |

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 変更ファイル | 自動修正対象のファイル |
| 標準出力 | 自動修正結果サマリ + 残課題（手動対応必要） |
| 終了状態 | レビュー完了 |

## 分岐の根拠

`--auto-fix` フラグあり。
