# Case 04: 非対話モードで自動削除

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "30 日より古い workspace を yes フラグで自動削除" |
| 引数 | `--days 30 --yes` |
| フラグ | `--yes` |
| 既存状態 | 30 日より古いセッションフォルダが複数存在 |

## 期待動作

### Phase 1: 引数解析
- `--yes` を検出 → 非対話モード
- `AskUserQuestion` は発火しない

### Phase 2: 対象収集 + バリデーション
- 通常通り収集
- バリデーションは必須（--yes でも省略不可）

### Phase 3: 削除実行
- 候補表示後、即削除
- バリデーション合格分のみ削除
- 失敗時は当該セッションのみスキップして続行

### Phase 4: サマリ出力
- 削除完了数、失敗数、解放容量

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | なし |
| 削除実行 | 候補のセッションフォルダがすべて削除される |
| 標準出力（要約） | 「===== クリーンアップ候補 =====」直後に「===== 削除結果 =====」 |
| 終了状態 | 成功（exit 0）。失敗があれば exit 2 |

## 分岐の根拠

このケースが分岐するトリガーは `--yes` フラグ = 指定あり である。AskUserQuestion をスキップして直接削除実行に進む。

## 安全装置

- バリデーションは必須（パス・リンク種別・進行中保護はすべて適用）
- `--yes` と `--dry-run` を同時指定した場合は `--dry-run` が優先（警告ログ出力）
