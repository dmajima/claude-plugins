# Case 03: 対話モードでキャンセル

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "古い作業フォルダを整理して" |
| 引数 | `--days 30`（既定） |
| フラグ | なし |
| 既存状態 | 30 日より古いセッションフォルダが存在 |

## 期待動作

### Phase 1: 候補表示
- スクリプトを `-Yes` なしで実行 → 候補表示のみ

### Phase 2: AskUserQuestion 確認
- 「{N} 件のセッションフォルダ ({合計容量} MB) を削除しますか？」
- 選択肢: 「削除する」「ドライランで終了」「キャンセル」
- ユーザが「キャンセル」を選択

### Phase 3: 中止処理
- スクリプト再実行は行わない
- ユーザに「操作を中止しました」と報告

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | なし |
| 削除実行 | なし |
| 標準出力（要約） | 候補一覧 + 「操作を中止しました」 |
| 終了状態 | 成功（exit 0、ユーザ意図によるキャンセル） |

## 分岐の根拠

このケースが分岐するトリガーは AskUserQuestion の選択結果 = "キャンセル" である。

## 関連ケース

- `case-02_interactive_approve.md`（承認選択）
- AskUserQuestion で「ドライランで終了」を選択した場合は `case-01_dry_run.md` の出力に類似（候補表示後に終了）
