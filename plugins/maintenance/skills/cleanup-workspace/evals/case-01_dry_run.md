# Case 01: ドライラン（候補表示のみ）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "古い作業フォルダを dry-run で確認して" |
| 引数 | `--days 30 --dry-run` |
| フラグ | `--dry-run` |
| 既存状態 | グローバル / プロジェクト両方に 30 日より古いセッションフォルダが複数存在 |

## 期待動作

### Phase 1: 引数解析
- `--dry-run` を検出してドライランモードに設定
- `--days 30`、`--scope both`（既定）

### Phase 2: 対象収集
- グローバル: `~/.claude/.local/work/*/` を列挙
- プロジェクト: `<repo>/.claude/.local/work/*/` を列挙
- 同一パスは重複除外

### Phase 3: 古さ判定 + 進行中保護
- 各セッションの再帰的 mtime を取得
- 30 日より古いものを候補に追加
- `progress.md` mtime が 5 分以内のセッションは候補から除外

### Phase 4: 候補表示
- 候補件数、合計容量、保護されたセッション数を表示
- 削除対象一覧（scope / path / size / mtime）を表示
- 「(dry-run) 実削除は行いません。」を出力

### Phase 5: 終了
- `AskUserQuestion` は発火しない
- 実削除は行わない（exit 0）

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | なし |
| 削除実行 | なし |
| 標準出力（要約） | 「===== クリーンアップ候補 =====」「(dry-run) 実削除は行いません。」 |
| 終了状態 | 成功（exit 0） |

## 分岐の根拠

このケースが分岐するトリガーは `--dry-run` フラグ = 指定あり である。
