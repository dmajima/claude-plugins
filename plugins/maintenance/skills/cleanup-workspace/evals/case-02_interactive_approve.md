# Case 02: 対話モードで削除承認

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "古い作業フォルダを整理して" |
| 引数 | `--days 30`（既定） |
| フラグ | なし |
| 既存状態 | グローバル / プロジェクト両方に 30 日より古いセッションフォルダが複数存在 |

## 期待動作

### Phase 1: 引数解析・対象収集
- 既定値で `--days 30`、`--scope both`、対話モード

### Phase 2: 候補表示（--yes なしで実行 → 候補表示のみ）
- スクリプトを `-Yes` なしで実行 → exit 0、候補表示のみ
- 「実削除を行うには -Yes フラグを付けて再実行してください（AskUserQuestion 経由推奨）。」を出力

### Phase 3: AskUserQuestion 確認
- 「{N} 件のセッションフォルダ ({合計容量} MB) を削除しますか？」
- 選択肢: 「削除する」「ドライランで終了」「キャンセル」
- ユーザが「削除する」を選択

### Phase 4: 削除実行
- スクリプトを `-Yes` 付きで再実行
- バリデーション合格分のみ削除
- 失敗時は当該セッションのみスキップして続行

### Phase 5: サマリ出力
- 削除完了数、失敗数、解放容量、保護されたセッション数

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | なし |
| 削除実行 | 候補のセッションフォルダがすべて削除される（バリデーション合格分） |
| 標準出力（要約） | 「===== クリーンアップ候補 =====」「===== 削除結果 =====」「削除完了: N 件」 |
| 終了状態 | 成功（exit 0） |

## 分岐の根拠

このケースが分岐するトリガーは AskUserQuestion の選択結果 = "削除する" である。
