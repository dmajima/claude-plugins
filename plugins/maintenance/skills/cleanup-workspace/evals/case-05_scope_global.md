# Case 05: スコープ別（global のみ）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "グローバルの古い作業フォルダだけ整理して" |
| 引数 | `--scope global --days 30` |
| フラグ | なし |
| 既存状態 | グローバル / プロジェクト両方に古いセッションあり |

## 期待動作

### Phase 1: 引数解析
- `--scope global` → グローバルのみ対象

### Phase 2: 対象収集
- グローバル `~/.claude/.local/work/*/` のみ列挙
- プロジェクト配下は列挙しない

### Phase 3: 候補表示
- スコープ列に「global」のみ表示
- プロジェクト配下のセッションは表示されない

### Phase 4 以降
- 対話モードで AskUserQuestion → 削除実行（case-02 と同様のフロー）

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | なし |
| 削除実行 | グローバル配下の対象セッションのみ削除 |
| 標準出力（要約） | 「スコープ: global」「削除対象一覧: [global] ...」 |
| 終了状態 | 成功 |

## 分岐の根拠

このケースが分岐するトリガーは `--scope` の値 = `global` である。`project` / `both` の場合は対象ルートが追加される。

## 関連ケース

- `--scope project` 指定時は project ルートのみ対象（global と対称的な動作）
- `--scope both`（既定）は両方を対象（他のケースで暗黙的にカバー）
