# Case 07: 削除対象 0 件

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "古い作業フォルダを整理して" |
| 引数 | `--days 30`（既定） |
| フラグ | なし |
| 既存状態 | 30 日より古いセッションフォルダが存在しない、または全件が進行中・keep-recent で保護 |

## 期待動作

### Phase 1: 引数解析・対象収集
- 通常通り

### Phase 2: 古さ判定 + 保護判定
- 候補件数 = 0 になる

### Phase 3: サマリ表示
- 「候補件数: 0 件」「合計容量: 0 MB」
- 削除対象一覧は出力されない（または「（対象なし）」と明示）

### Phase 4: 終了
- AskUserQuestion は発火しない
- 削除実行も行わない（exit 0）
- ユーザに「対象がありませんでした」と報告

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | なし |
| 削除実行 | なし |
| 標準出力（要約） | 「候補件数: 0 件」「対象がありませんでした」 |
| 終了状態 | 成功（exit 0、削除対象なし） |

## 分岐の根拠

このケースが分岐するトリガーは 候補件数 = 0 である。

## エッジケース

| 状況 | 動作 |
|-----|------|
| ルートディレクトリ自体が不在 | 「対象ルートが見つかりませんでした」を出力（同様に exit 0） |
| 全件が進行中保護 | 「保護されたセッション: 進行中: N 件」を表示 |
| 全件が keep-recent で保護 | 「保護されたセッション: keep-recent: N 件」を表示 |
