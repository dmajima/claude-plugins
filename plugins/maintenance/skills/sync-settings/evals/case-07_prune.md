# Case 07: `--prune` でローカルのみのファイル削除

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "リモートに合わせて余分なローカルファイルも削除して" |
| 引数 | `--strategy overwrite --prune` |
| フラグ | `--prune` |
| 既存状態 | リモートには存在せず、ローカル `~/.claude/skills/` 配下にのみ存在するスキルが複数あり |

## 期待動作

### Phase 4: 差分検出
- ローカルのみのファイルを `[DEL]` として候補に追加
- リモートと一致するファイルは `[OK]`（表示省略）

### Phase 5: AskUserQuestion 確認
- 通常の確認 + `[DEL]` が 10 件超なら追加の AskUserQuestion で再確認

### Phase 7: 同期適用
- `[DEL]` 件数分のローカルファイル削除
- 削除直前にも除外パターン（認証情報等）を再確認

### Phase 9: サマリ
- 「[DEL] N 件 (--prune)」を含む

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | バックアップ（削除されるファイルもバックアップに含まれる） |
| 標準出力（要約） | 「[DEL] N 件」「(--prune)」を含むサマリ |
| 終了状態 | 成功 |

## 分岐の根拠

このケースが分岐するトリガーは `--prune` フラグ + Strategy = "overwrite" である。`merge` / `skip` 戦略との組み合わせは warning + 無効化される。

## 安全装置

- バックアップは必須（削除前に保存される）
- 削除対象 10 件超では追加 AskUserQuestion で再確認
- 認証情報・Git メタデータは削除対象から自動除外
