# Case 03: 対話モードでキャンセル

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "Claude の設定を Git から同期して" |
| 引数 | `--repo https://github.com/myaccount/claude-settings` |
| フラグ | なし |
| 既存状態 | リモートに差分あり |

## 期待動作

### Phase 1〜4: 設定解決〜差分検出
- case-01 と同じ

### Phase 5: AskUserQuestion 確認
- 「{N} 件のファイル変更を ~/.claude/ に適用しますか？」
- ユーザが「キャンセル」を選択

### Phase 6: 中止処理
- スクリプト再実行（`--yes` 付き）は行わない
- バックアップ取得もしない
- `sync-config.json` も更新しない（前回の値を保持）
- ユーザに「操作を中止しました」と報告

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | クローン先のみ（`repo/` 配下） |
| ファイル変更 | なし |
| 標準出力（要約） | 差分一覧 + 「操作を中止しました」 |
| 終了状態 | 成功（exit 0、ユーザ意図によるキャンセル） |

## 分岐の根拠

このケースが分岐するトリガーは AskUserQuestion の選択結果 = "キャンセル" である。

- 「戦略を変更して再表示」を選択した場合は AskUserQuestion で戦略選択フローへ
