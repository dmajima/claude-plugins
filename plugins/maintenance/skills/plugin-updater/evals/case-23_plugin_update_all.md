# case-23 /update-all コマンドによる全プロジェクト更新

/update-all コマンドで全プロジェクトのプラグインを一括更新する正例。

## 入力

| 項目 | 値 |
|-----|------|
| 起動フレーズ | "/update-all" |
| モード | 非対話 |

## 期待

- plugin-updater スキルが target=all で起動する
- 全プロジェクトのプラグインが更新対象になる
- 更新結果サマリが報告される

## 期待出力

| 出力 | 内容 |
|-----|------|
| 標準出力 | プロジェクトごとの更新結果サマリ |

## 分岐の根拠

SKILL.md の実行モード判定で /update-all コマンド経由 → target=all に該当。
