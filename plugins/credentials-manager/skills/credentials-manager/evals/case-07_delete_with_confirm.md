# Case 07: 削除（対話モードで確認あり）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "openai-api-key を削除して。" |
| 引数 | なし |
| フラグ | なし |
| 既存状態 | `credentials.json` に `openai-api-key` が存在 |

## 期待動作

### Phase 1: パス解決と読み込み

- 解決パスから `credentials.json` を読み込み
- `openai-api-key` エントリの存在を確認

### Phase 2: 削除前確認

- `AskUserQuestion` で「`openai-api-key` (`sk-p****f456`) を削除します。よろしいですか?」を提示
- 選択肢: 「削除する」「キャンセル」

### Phase 3: 削除実行

- ユーザが「削除する」を選択した場合のみエントリを削除し、ファイル書き戻し
- キャンセル時は変更なし

### Phase 4: 完了通知

- 削除完了を通知（フル値非表示）

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | `credentials.json`（該当エントリ削除） |
| 標準出力（要約） | 削除確認質問 → ユーザ承諾後に "Deleted credential 'openai-api-key'." |
| 終了状態 | 成功（または "キャンセル" 選択時は変更なし終了） |

## 分岐の根拠

このケースは「削除（delete）+ 対話モード」分岐に該当する。誤削除防止のため `AskUserQuestion` 確認が必須。
