# Case 10: 取得（retrieve、対象なし）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "保存してある Stripe のキーを使って API を叩いて。" |
| 引数 | なし |
| フラグ | なし |
| 既存状態 | `credentials.json` に Stripe 関連の認証情報なし |

## 期待動作

### Phase 1: パス解決と読み込み

- 解決パスから `credentials.json` を読み込み

### Phase 2: 名前検索

- "Stripe" で部分一致検索 → ヒット 0 件

### Phase 3: 候補提示と保存提案

- 既存の認証情報名一覧（マスク済み値付き）をユーザに提示
- `AskUserQuestion` で「Stripe の認証情報は見つかりません。提供しますか?」を確認
- 選択肢: 「認証情報を提供する」「中止する」

### Phase 4: 選択された経路で実行

- 「提供する」 → save フローへ遷移
- 「中止する」 → API 呼び出しを行わず終了

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | save 選択時のみ `credentials.json` 更新 |
| 標準出力（要約） | 候補不在通知 + 既存名一覧 + 提案質問 + ユーザ選択後の動作 |
| 終了状態 | ユーザ選択に応じる |

## 分岐の根拠

このケースは「取得（retrieve）+ 一致なし」分岐に該当する。候補提示と保存フローへの遷移を検証する。
