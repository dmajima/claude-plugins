# Case 02: 保存済み認証情報の一覧表示

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "保存してある認証情報を一覧表示して。" |
| 引数 | なし |
| フラグ | なし |
| 既存状態 | `credentials.json` に 2 件保存済み（`openai-api-key` / `github-token`） |

## 期待動作

### Phase 1: パス解決と読み込み

- 解決パス（リポジトリ内なら project-scoped）から `credentials.json` を読み込み
- 不在なら「保存済み認証情報はありません」と表示して終了

### Phase 2: 表形式表示

- 名前 / 種別 / 説明 / 関連ドメイン / マスク値 / 更新日時を表で表示
- 各値はマスク済み（`<先頭4>****<末尾4>`、8 文字以下なら `****`）
- 表下にスコープと保存パスを併記

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | なし（読み取りのみ） |
| 標準出力（要約） | 名前・種別・マスク値・関連ドメイン・更新日の表 + スコープ表示 |
| 終了状態 | 成功 |

## 分岐の根拠

このケースは「一覧（list）」分岐に該当する。書き込みなし、ユーザ確認なし。
