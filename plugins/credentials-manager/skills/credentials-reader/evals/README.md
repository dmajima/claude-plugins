# Evals: credentials-reader

このディレクトリは `credentials-reader` スキル（参照系）の動作分岐の期待挙動を例示する。書き込み系の評価ケースは `../../credentials-manager/evals/` を参照すること。

## ケース一覧

| ケース | 内容 | 主な分岐根拠 |
|-------|-----|-------------|
| case-01 | URL アクセス時の自動マッチ（1 件ヒット） | 暗黙トリガー（URL 自動マッチ・単一） |
| case-02 | URL アクセス時の自動マッチ（複数件ヒット） | 暗黙トリガー（URL 自動マッチ・複数、`AskUserQuestion`） |
| case-03 | URL アクセス時の自動マッチ（0 件 → 引き継ぎ） | 暗黙トリガー（0 件、`credentials-manager` への引き継ぎ） |
| case-04 | 取得（retrieve、対象あり） | 名前部分一致単一ヒット |
| case-05 | 取得（retrieve、対象なし） | 候補不在時の保存提案 → 引き継ぎ |
| case-06 | 一覧（list） | 参照目的の表形式表示 |
| case-07 | プロアクティブ検出（GitHub トークン） | パターン検出 → 保存提案 → 引き継ぎ |
| case-08 | 非対話モードでの自動マッチ（複数件、最新採用） | 実行モード判定（非対話） |
| case-09 | ローカルホスト URL（auto-match スキップ） | スキップ条件（誤検出回避） |
| case-10 | JSON パース失敗時の引き継ぎ提案 | エラー系（書き込み修復は manager 責務） |

## 実行確認方法

各ケースの「入力」セクションのフレーズで Claude Code を起動し、「期待動作」「期待出力」と一致することを目視確認する。

## 重要な検証観点

| 観点 | 確認内容 |
|-----|--------|
| グローバルルール非依存 | `~/.claude/rules/security/credentials-management.md` 不在環境でも case-01 / case-02 / case-03 の暗黙トリガーが発火すること |
| マスキング | フル値が会話出力に出ない |
| 引き継ぎ | 書き込みが必要な場合、`credentials-manager` へ正しく引き継がれること（フル値を引き継ぎログに残さない） |
| 軽量起動 | hook 経由で起動した際、本スキルのみ読み込まれ `credentials-manager` の `references/` は読み込まれないこと |
