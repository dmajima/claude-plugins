# Case 06: 一覧表示（list、参照目的）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "保存してある認証情報を一覧表示して。" |
| 引数 | なし |
| フラグ | なし |
| 既存状態 | `credentials.json` に複数のエントリが存在 |

## 期待動作

### Phase 1: パス解決 + 読み込み

- 解決パスから `credentials.json` を読み込み

### Phase 2: 表形式出力

- 名前 / 種別 / 説明 / 関連ドメイン / マスク値 / 更新日時を表形式で表示
- 表の下に保存先パスとスコープ（project-scoped / user-scoped）を併記

### Phase 3: 後続操作の案内

- 「追加・編集・削除を行いますか？」と尋ね、希望があれば **`/credentials-manager:manage` コマンド** または `credentials-manager` への引き継ぎを案内

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | なし（読み取りのみ） |
| 標準出力（要約） | 認証情報の表形式表示 + パス + スコープ + 後続操作案内 |
| 終了状態 | 成功 |

## 分岐の根拠

「list 系（参照目的）」分岐。マスキングが守られ、フル値が表示されないことを検証する。書き込み操作には引き継ぎが必要であることをユーザに案内する。

- `/credentials-manager:manage` コマンド（メニューUIから一覧+操作）
