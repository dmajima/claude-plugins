# Case 05: 取得（retrieve、対象なし → credentials-manager 引き継ぎ）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "保存してある AWS の認証情報を使って S3 にアクセスして。" |
| 引数 | なし |
| フラグ | なし |
| 既存状態 | `credentials.json` に AWS 関連エントリは存在しない |

## 期待動作

### Phase 1: パス解決 + 読み込み

- `credentials.json` を読み込み（不在時は空ストア）

### Phase 2: 名前検索

- 「AWS」キーワードに合致する認証情報を検索 → 0 件

### Phase 3: 候補提示と保存提案

- 「AWS 関連の認証情報は保存されていません。保存しますか？」と `AskUserQuestion` で確認

### Phase 4: 引き継ぎ判断

- ユーザ承諾 → `credentials-manager` を起動 → 保存フロー
- 拒否 → reader を終了し、ユーザに「保存しない」結果を通知

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル（承諾時） | `credentials.json`（解決パス） |
| 標準出力（要約） | 候補不在通知 + 引き継ぎ案内 + 保存完了 or 中止 |
| 終了状態 | 成功 |

## 分岐の根拠

「retrieve + 一致なし → 引き継ぎ」分岐。引き継ぎ時にフル値を引き継ぎログに残さないこと、reader が単独で書き込みを行わないことを検証する。
