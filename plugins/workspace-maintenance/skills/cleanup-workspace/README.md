# cleanup-workspace (skill)

Claude Code のセッション作業領域 `.claude/.local/work/` に蓄積した古いセッションフォルダ・一時ファイルを多段の安全装置（バリデーション + ドライラン + AskUserQuestion）付きで削除するスキル。

## このドキュメントについて

このファイルは **人間向けのリファレンス** です。Claude Code がスキル動作中に参照することはありません。スキル動作の本体は `SKILL.md` および `references/` 配下を参照してください。

## 責務（要約）

- 古いセッションフォルダ（`yyyyMMdd_nn_*` 形式）の安全削除
- グローバル（`~/.claude/.local/work/`）と現在のリポジトリ配下の双方を対象
- ドライラン + AskUserQuestion + パスバリデーションによる多重安全装置

## 導入手順

### 前提

- Claude Code がインストール済み
- `workspace-maintenance` プラグインがインストール済み
- PowerShell 7+ が利用可能（Windows 主軸）

### 起動方法

以下のフレーズで自動起動します:

- 「古い作業フォルダを整理して」
- 「セッションフォルダのクリーンアップ」
- 「`.claude/.local/work/` を掃除」
- 「workspace のメンテナンス」
- 「古い tmp ファイルを削除」

## 利用方法（最小例）

### 例 1: まずドライランで確認

ユーザ:
> `.claude/.local/work/` を掃除する候補を表示して

Claude（要約）:
> グローバル + 現在のリポジトリの両方を走査し、30 日以上古いセッションフォルダの一覧と合計解放予定容量を表示。実削除は行わない。

### 例 2: 対話モードで削除実行

ユーザ:
> 古い作業フォルダを整理して

Claude（要約）:
> 候補を表示し、`AskUserQuestion` で「削除する / ドライランで終了 / キャンセル」を確認。「削除する」選択時のみ実削除を実行し、サマリを表示。

### 例 3: 最新 3 件は保持

ユーザ:
> 90 日以上古いやつだけ削除、ただし最新 3 件は残して

Claude（要約）:
> `--days 90 --keep-recent 3` 相当で対象を絞り込み、対話モードで削除実行。

## トリガー例

| 発話 | 既定動作 |
|-----|---------|
| 「古い作業フォルダを整理して」 | 対話モードで削除確認 |
| 「dry-run で見せて」 | `--dry-run` 相当 |
| 「30 日より古い session を全部消して」 | 対話モードで削除確認（既定閾値） |
| 「最新 N 件は残して」 | `--keep-recent N` 相当 |
| 「tmp/ だけ掃除して」 | `--include-tmp` 相当（セッションフォルダ自体は保持） |

## 安全装置

| 装置 | 内容 |
|-----|------|
| パスバリデーション | `.claude/.local/work/` 配下の `yyyyMMdd_nn_*` 形式のみ削除可。`work/` 自体や祖先ディレクトリは絶対に削除しない |
| シンボリックリンク保護 | リンクは追従せず、リンク自体も削除対象外 |
| 進行中セッション保護 | `progress.md` の mtime が 5 分以内なら保護 |
| ドライラン推奨 | 既定動作は候補表示のみ。実削除には明示承認が必要 |
| AskUserQuestion による最終確認 | 対話モードでは削除前に必ず確認 |
