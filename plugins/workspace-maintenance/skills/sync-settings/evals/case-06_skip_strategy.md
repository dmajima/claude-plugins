# Case 06: skip 戦略で既存保持

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "skip 戦略で同期して（既存ファイルは変更せず新規だけ取り込む）" |
| 引数 | `--strategy skip` |
| フラグ | なし |
| 既存状態 | リモートに ADD（新規） + MOD（差分あり）の両方が含まれる |

## 期待動作

### Phase 5: 同期適用（skip）
| 状況 | 動作 |
|-----|------|
| 両方に存在 | スキップ（既存保持） |
| リモートのみ | 新規作成 |
| ローカルのみ | 保持 |

### サマリ
- [ADD] のみ適用件数に計上
- [MOD] はすべてスキップ（適用件数には計上されない）

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | バックアップ + リモートの新規ファイルが追加された `~/.claude/` |
| 標準出力（要約） | 「戦略: skip」「適用件数: {ADD件数} 件」 |
| 終了状態 | 成功 |

## 分岐の根拠

このケースが分岐するトリガーは `--strategy skip` 指定である。

## 重要な動作

- 既存ローカル設定の更新は取り込まれない
- 「初期セットアップのみ自動化、以降は手動同期」というユースケース向け
- バグ修正された rules / skills も取り込まれないため、定期的に overwrite 戦略への切り替えを検討する
