# Case 07: 非対話モード

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | 「TODO コメントになっている入力バリデーションを実装して --non-interactive」 |
| 引数 | タスク説明 |
| フラグ | `--non-interactive` |
| 既存状態 | PHP（Laravel）プロジェクト。仕様の細部（エラーメッセージ文言）が未指定 |

## 期待動作

### 全フェーズ共通
- `AskUserQuestion` を発火させず、不明点は **最も保守的な解釈** を採用して進行
- 採用したデフォルト判断を各成果物の「確認事項と回答」欄に必ず記録（確認方法 = デフォルト採用）

### Phase 1: Intake
- エラーメッセージ文言は既存バリデーションの文言スタイルに合わせる判断を記録

### Phase 3: Design
- 複数方針が拮抗した場合も推奨案を自動採用し、根拠を記録

### Phase 5: Self-Review
- Critical / High 指摘の修正は通常どおり実施（遡行に確認は不要）
- 実装済みコードの破棄を伴う遡行が必要になった場合は、変更を残したまま遡行し、その旨を記録

### 品質ゲート FAIL で解決不能の場合
- 中断してユーザに状況を報告する（無限に自動続行しない）

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| ユーザへの確認 | 0 回（AskUserQuestion 不発火） |
| 生成ファイル | 全成果物にデフォルト判断の記録あり |
| 終了状態 | 成功 / 解決不能時は中断 + 状況報告 |

## 分岐の根拠

このケースが分岐するトリガーは フラグ = `--non-interactive` である。
