## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | 「通知機能を設計して、そのまま実装まで進めて」 |
| 引数 | なし |
| フラグ | なし |
| 既存状態 | 任意の対応言語プロジェクト |

## 期待動作

- 依頼に実装が含まれることを検知し、本スキル（設計のみ）ではなく `orchestrator-coding` が適切であることを判断
- `orchestrator-coding` を起動して 6 フェーズ実装ワークフローとして遂行する（設計は Phase 3 として実施される）
- 設計だけを別成果物として先に確認したい場合はその旨を伝えれば `orchestrator-design` を使う、という選択肢を必要に応じて案内

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 起動スキル | `orchestrator-coding`（本スキルの 4 フェーズは開始しない） |
| 終了状態 | orchestrator-coding のフローとして継続 |
