# Case 03: 過去履歴除去

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "`dev-toolkit` の README から過去履歴を除去して最新化" |
| 引数 | `--plugin dev-toolkit` |
| フラグ | なし |
| 既存状態 | README 既存、「## 変更履歴」「## v0.x で追加」等のセクションあり |

## 期待動作

### Phase 1: 過去履歴検出

以下のパターンを検出:

- 「変更履歴」「Changelog」「Release Notes」セクション
- バージョン番号付きの履歴記述（`v0.1: ...`）
- 「以前は ~~」「~~削除済~~」等の打消し記述
- 「廃止予定」「Deprecated」マーク付き機能

### Phase 2: 除去確認

検出した履歴項目をユーザに提示し、除去可否を確認。一部を残したい場合は対話で選択。

### Phase 3: 除去 + 書き戻し

承認された範囲の履歴を削除し、最新版のみの記述に整形する。

### Phase 4: 検証

過去履歴セクション・打消し記述が残っていないことを確認。

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 変更ファイル | `plugins/dev-toolkit/README.md` |
| 標準出力 | 除去項目サマリ + 「最新版のみの構成に整形」 |
| 終了状態 | 成功 |

## 分岐の根拠

既存 README に過去履歴記載検出 である。
