# Case 03: 重複検出（マージ提案）

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "新プラグイン `plugin-builder-v2` を公開" |
| 引数 | `plugin-builder-v2` |
| フラグ | なし |
| 既存状態 | 既存に `plugin-builder` プラグインがあり、機能領域が類似 |

## 期待動作

### Phase 1: 現状確認

未登録を確認。

### Phase 2: 重複チェック

[`../references/duplication-check.md`](../references/duplication-check.md) の評価:

| 観点 | 評価 |
|-----|-----|
| 名前類似 | 高（部分文字列一致） |
| description 類似 | 中（キーワード一部重複） |
| 機能領域類似 | 高（同種スキル提供） |

総合: **高重複** → マージ提案。

### Phase 3: ユーザ提示

```text
類似プラグインを検出:
- `plugin-builder` — 類似ポイント: 名前部分一致 + 機能領域同一

選択肢:
1. 既存 `plugin-builder` へのマージ
2. 新規登録続行（差別化点明記）
3. キャンセル
```

### Phase 4: 選択分岐

| 選択 | 動作 |
|-----|------|
| 1 | `plugin-creator` の追加シナリオを案内、本スキル終了 |
| 2 | 差別化点を確認、description 更新後に新規登録続行 |
| 3 | 何もしない |

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 変更ファイル | 選択により異なる |
| 標準出力 | 重複検出 + 選択肢、選択後の動作結果 |
| 終了状態 | 選択により異なる |

## 分岐の根拠

既存と類似度高（高重複検出）。
