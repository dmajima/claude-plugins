# agent-creator (skill)

Claude Code のサブエージェント・エージェントチームを設計・作成するスキル。

## このドキュメントについて

このファイルは **人間向けのリファレンス**。Claude Code がスキル動作中に参照することはない。

## 責務（要約）

エージェント・チームの設計・作成のみ。スキル本体・プラグイン外形等は他スキルが担当。

## トリガー例

- 「コードレビュー用エージェントを作って」
- 「セキュリティ評価チームを編成」
- 「`code-reviewer` エージェントに観点を追加」

## 関連スキル

| スキル | 関係 |
|-------|------|
| `skill-creator` | エージェントを利用するスキル本体作成 |
| `plugin-creator` | プラグイン内に配置する場合の外形作成 |
| `extension-reviewer` | 完成後のエージェント定義レビュー |

## 主要参照ファイル

| ファイル | 内容 |
|---------|------|
| `SKILL.md` | スキル定義とトリガー条件 |
| `references/procedures.md` | 詳細手順 |
| `references/team-design.md` | チーム設計の詳細ルール |
| `evals/` | 動作分岐の期待挙動 |
