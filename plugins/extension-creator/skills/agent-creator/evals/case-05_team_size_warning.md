# Case 05: チームサイズ不足の警告

## 入力

| 項目 | 値 |
|-----|---|
| 起動フレーズ | "コードレビューチームを 2 名で編成" |
| 引数 | `--team code-review --members "implementation-engineer,test-engineer"` |
| フラグ | `--team` |
| 既存状態 | 各メンバー既存 |

## 期待動作

### Phase 1: メンバー数検証

メンバー数 2 名 → レビュー系チームの最低 3 名を満たさない。

### Phase 2: 警告とユーザ確認

```text
レビュー系チームは最低 3 名が推奨です（[`team-design.md`](team-design.md) のサイズ基準）。
現在のメンバー: implementation-engineer, test-engineer（2 名）

選択肢:
1. メンバーを追加（推奨候補: security-engineer, architect, project-leader）
2. このまま 2 名で進行（理由を明記）
3. キャンセル
```

### Phase 3: 選択分岐

| 選択 | 動作 |
|-----|------|
| 1 | 追加メンバーを確認後、3 名以上で編成 |
| 2 | チーム定義ファイルに「サイズ例外」コメントを残し、進行 |
| 3 | 何もせず終了（成功・キャンセル扱い） |

## 期待出力

| 項目 | 期待値 |
|-----|-------|
| 生成ファイル | 選択により異なる |
| 標準出力 | サイズ不足警告 + 選択肢 |
| 終了状態 | 選択により異なる |

## 分岐の根拠

レビュー系チーム + メンバー数 < 3 である。
