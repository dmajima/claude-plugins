# 実行手順詳細

`command-creator` の詳細実行手順。

## 配置先の選択

| 用途 | 配置先 |
|-----|-------|
| プロジェクト固有 | `<repo>/.claude/commands/{name}.md` |
| グローバル | `~/.claude/commands/{name}.md` |
| プラグイン同梱 | `plugins/{plugin-name}/commands/{name}.md` |

## テンプレート展開手順

### 1. ベースコピー

`${CLAUDE_PLUGIN_ROOT}/templates/command/command.md` を配置先にコピー。

### 2. プレースホルダ置換

| プレースホルダ | 置換値 |
|--------------|-------|
| `{コマンドの 1 行説明（60 文字以内）}` | description |
| `{パターン 1}` | 引数パターン |
| `{skill-name-1}` | ルーティング先スキル |
| `{確認項目 1}` | 引数空時の確認項目 |

### 3. プロンプト本体の充填

テンプレートの構造を保ちつつ、コマンド固有のロジックを末尾に追加する。

## オーケストレータ型コマンドの場合

`/extension` や `/publish` のように複数スキルへルーティングするコマンドは以下を含める:

```markdown
## ルーティング

| 引数パターン | 起動スキル |
|------------|----------|
| `skill <name>` | `skill-creator` |
| `plugin <name>` | `plugin-creator` |
| `command <name>` | `command-creator` |
| `agent <name>` | `agent-creator` |
| `hook <name>` | `hook-creator` |
| `readme <target>` | `readme-creator` |
| `review <target>` | `extension-reviewer` |
| `publish <plugin>` | `marketplace-publisher` |
```

## 単機能型コマンドの場合

単一のロジックを実行する場合は `## ルーティング` を削除し、本文に直接プロンプトを書く。

## description 設計

| 用途 | 文字数 | 例 |
|-----|-------|---|
| プラグイン同梱コマンド | 60 文字以内 | `拡張要素の作成・公開を支援` |
| プロジェクト用コマンド | 60 文字以内 | `現在のブランチでテストを実行` |

避けるべき表現:

| 避ける | 理由 |
|-------|------|
| 引数仕様（`--foo` 等の記述） | 本文に書く |
| 複数機能を並列列挙 | 60 文字超過しやすい |
| 過去形・未来形 | 現在形で統一 |

## 引数空時の動作設計

| 戦略 | 適用条件 |
|-----|---------|
| 必須引数を対話で確認 | 必須引数あり |
| ヘルプ表示 | 引数仕様が複雑 |
| デフォルト動作実行 | 引数なしでも意味のある動作が定義可能 |

## ルーティング設計

### 完全一致ルーティング

引数の最初のトークンと完全一致でスキル選択。

### パターンマッチング

引数全体を正規表現で評価し、最初に一致するルートへ。

### フォールバック

どのルートにも一致しない場合の動作を必ず定義。

| フォールバック | 動作 |
|-------------|------|
| ヘルプ表示 | 利用可能パターンを提示 |
| デフォルトルート | 最も一般的なルートを起動 |
| エラー | 引数不正としてユーザに修正を促す |
