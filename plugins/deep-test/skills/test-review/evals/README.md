1 ケース 1 ファイルで、スキルの規範（SKILL.md / references/ / プラグイン共通 references）に基づく分岐ごとに期待動作を定義する。

## ケースファイルの構成

各ケースファイルは以下のセクションで構成する。

| セクション | 内容 |
|-----------|------|
| 入力 | 委譲 args または起動フレーズ / 起動形態（委譲・単独）・前提状態 |
| 分岐の根拠 | SKILL.md / references のどの規範に基づく分岐か（ファイル名・章を明記） |
| 期待動作 | 検証可能な期待動作の箇条書き（呼ばれるエージェント・生成物・判定・返却内容） |
| 期待出力 | 生成ファイル / 標準出力（要約）/ 終了状態の表（判定と返却内容への参照でよい） |
| 関連ケース | 対になる分岐・前提となるケースへの参照 |

## 文脈の軸について

本スキルの evals は「設計文脈 / 結果文脈」の切り替えを主軸に検証する。
文脈を確定できない場合の対話 / 非対話の分岐は case-05（AskUserQuestion 確認）と case-07（エラー中断）の対で扱い、レビュー対象が 0 件の場合のエージェント起動省略は case-06 で扱う。
レビュー対象の不在は 2 系統を区別する: **draft 0 件（全 approved）** は正常返却（case-06）、**成果物が物理的に不在**（設計文脈: 計画 / ケース不在 = case-08、結果文脈: 対象 run 不在 = case-09）はエラー中断。
どの分岐でも共通する不変条件: 文脈別エージェント構成の 1 メッセージ内並列起動（対象 0 件時は未起動）、全プロンプトへの共通注入事項（agents.md 4.3 章）の付与、指摘への重要度 + 信頼度付与と重複統合（信頼度 40 未満は参考指摘として判定カウント外）、test-results.yaml への不書き込み、エージェントに総合判定をさせない。
