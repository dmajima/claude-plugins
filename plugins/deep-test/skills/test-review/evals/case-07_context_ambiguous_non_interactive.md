# case-07 文脈判定不能 × 非対話（推測で進めずエラー中断）

非対話モードで入力から設計文脈 / 結果文脈を確定できないケース。AskUserQuestion にフォールバックせず、推測でも進めず、エラー中断して明示指定を案内することを検証する。

## 入力

| 項目 | 内容 |
|-----|------|
| 委譲 args | 「orderapp-web のテストをレビューして」相当の依頼本文 + `--non-interactive`（`context=` なし・対象ファイルパスの指定なし） |
| 起動形態 | 委譲（オーケストレータ経由・非対話） |
| 前提 | `{target-slug}/` に test-plan.md / test-cases.yaml / test-results.yaml（実行済み run あり）が**すべて**存在し、依頼文言からはどちらの文脈か確定できない |

## 分岐の根拠

SKILL.md「実行モード判定」（非対話: 文脈が判定できない場合はエラー中断・推測で進めない）、references/review-procedures.md 2 章の判定規則 6（両方の材料が混在・いずれも欠落 → 非対話はエラー中断〔推測で進めない〕）。

## 期待動作

- 判定規則 1〜5 を順に評価し、確定できないことを確認してから曖昧ケースの分岐に入る（設計文脈と即断しない）
- 非対話モードのため **AskUserQuestion を発行しない**（対話へのフォールバックをしない）
- エージェントを 1 体も起動せず**エラーで中断**し、`context=design` / `context=results` の明示指定による再実行を案内する
- どちらかの文脈に決め打ちで進まない・両文脈のエージェント構成を同時に起動して両方レビューするという回避もしない
- 中断時にファイル（test-cases.yaml / test-results.yaml）への書き込みを行わない

## 期待出力

| 区分 | 内容 |
|-----|------|
| 生成ファイル | なし（エージェント未起動・test-cases.yaml / test-results.yaml へ一切書き込まない） |
| 標準出力（要約） | 文脈を確定できなかった旨と、`context=design` / `context=results` の明示指定による再実行案内（エラーとして返却） |
| 終了状態 | エラーで中断（推測で進めない・AskUserQuestion へのフォールバックもしない） |
