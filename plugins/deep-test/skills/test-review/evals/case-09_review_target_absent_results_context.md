# case-09 レビュー対象成果物の不在（結果文脈: 対象 run 不在）→ エラー中断

文脈は結果と確定しているがレビュー対象の run が存在しないケース。結果文脈で指定 run_id が存在しない、または `runs[]` が 0 件で対象 run を確定できない場合に、エージェントを起動せず「レビュー対象なしで進めない」としてエラー中断することを検証する。case-08（設計文脈: 計画 / ケース不在）の結果文脈側の対。文脈判定不能（case-05 / 07）とは異なり本ケースは文脈が確定している。

## 入力

| 項目 | 内容 |
|-----|------|
| 委譲 args | `context=results target=<slug> base=<base> run-id=R20260717-999999`（存在しない run_id）。または run-id 無指定で test-results.yaml の run が 0 件 |
| 起動形態 | 委譲（オーケストレータ経由）/ 単独起動でも同一挙動 |
| 前提 | test-results.yaml が存在しない・存在しても `runs[]` が空、または指定 run_id に一致する run がない |

## 分岐の根拠

`${CLAUDE_SKILL_DIR}/references/review-procedures.md` 4.1 章（結果文脈: `results=`〔省略時は `{target-slug}/test-results.yaml`〕を Read し、対象 run を確定する〔`run=` 指定があればその run、なければ最新 run〕。読み取りのみ）・3.1 章と同じ「レビュー対象なしで進めない」原則（指定 run が存在しない・run が 0 件で確定できない場合は中断）・2 章（推測で進めない原則）、SKILL.md「重要な制約」（推測で進めない・test-results.yaml へ書き込まない）。

## 期待動作

- `results=`（省略時は既定パス）を Read し、対象 run を確定する。指定 run_id が存在しない・`runs[]` が 0 件で確定できない場合は **エラー中断**する。defect-analyst / user-perspective-reviewer を 1 体も起動しない
- 対象 run 不在を「レビュー対象なし・PASS」と誤って結論しない（実行未実施であって検証済みではない）
- 中断時に「対象 run が存在しない」旨と、run を含むモードでの実行の案内、または正しい `run-id=` の指定を案内する
- test-results.yaml へ書き込まない（読み取りのみ・注釈登録もしない）
- レビュー対象 0 件でも空のレビューレポートを PASS として捏造しない

## 期待出力

| 区分 | 内容 |
|-----|------|
| 生成ファイル | なし（エージェント未起動・test-results.yaml へ一切書き込まない） |
| 標準出力（要約） | 「対象 run が存在しないため中断した」旨 + run 実行 / `run-id=` 指定の案内 |
| 終了状態 | エラーで中断（レビュー対象なしで進めない・PASS と誤結論しない） |
