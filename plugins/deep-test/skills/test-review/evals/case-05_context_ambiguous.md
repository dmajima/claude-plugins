# case-05 文脈判定不能 × 対話（AskUserQuestion で確認）

対話モードで入力から設計文脈 / 結果文脈を確定できないケース。推測で進めず AskUserQuestion で文脈を確認し、選択された文脈の手順へ進むことを検証する。

## 入力

| 項目 | 内容 |
|-----|------|
| 起動フレーズ | 「orderapp-web のテストをレビューして」（`context=` なし・対象ファイルパスの指定なし） |
| 起動形態 | 単独（ユーザー直接起動・対話） |
| 前提 | `{target-slug}/` に test-plan.md / test-cases.yaml / test-results.yaml（実行済み run あり）が**すべて**存在し、依頼文言からはどちらの文脈か確定できない |

## 分岐の根拠

SKILL.md「実行モード判定」（対話: 文脈が曖昧な場合のみ AskUserQuestion で確認）、references/review-procedures.md 2 章の判定規則 6（両方の材料が混在・いずれも欠落 → 対話は AskUserQuestion で確認）。

## 期待動作

- 判定規則 1〜5 を順に評価し、確定できないことを確認してから曖昧ケースの分岐に入る（設計文脈と即断しない）
- AskUserQuestion で「設計レビュー（テストケースのレビュー・承認）」「結果レビュー（実行結果・NG の検証）」の 2 択を説明付きで提示し、選択された文脈で 3 章 / 4 章の手順へ進む
- 文脈が曖昧でない場合には AskUserQuestion を発行しない（確認は曖昧な場合のみ）
- 文脈確定前にエージェントを起動しない・どちらの文脈にも決め打ちで進んで両構成のエージェントを同時に起動する、という動作をしない（文脈ごとの構成は agents.md 1 章で固定）
- 文脈確定前にファイル（test-cases.yaml / test-results.yaml）への書き込みを行わない

## 期待出力

| 区分 | 内容 |
|-----|------|
| 生成ファイル | 文脈確定前はなし（エージェント未起動・書き込みなし）。選択後は選択された文脈の通常フローに従う |
| 標準出力（要約） | 「設計レビュー / 結果レビュー」の 2 択（説明付き）を AskUserQuestion で提示し、選択された文脈の手順へ続行 |
| 終了状態 | ユーザー選択で文脈を確定して続行（推測で進めない） |
