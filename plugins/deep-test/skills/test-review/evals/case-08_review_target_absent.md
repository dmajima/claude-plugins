# case-08 レビュー対象成果物の不在（設計文脈: 計画 / ケース不在）→ エラー中断

文脈は設計と確定しているがレビュー対象の成果物が物理的に存在しないケース。設計文脈で test-plan.md / test-cases.yaml が不在の場合に、エージェントを起動せず「レビュー対象なしで進めない」としてエラー中断することを検証する。文脈判定不能（case-05 / 07）とは異なり本ケースは文脈が確定している。結果文脈（対象 run 不在）は case-09 で扱う。

## 入力

| 項目 | 内容 |
|-----|------|
| 委譲 args | `context=design target=<slug> base=<base>`（対象成果物のパス指定なし・既定探索先も不在） |
| 起動形態 | 委譲（オーケストレータ経由）/ 単独起動でも同一挙動 |
| 前提 | `{target-slug}/` 直下に test-plan.md / test-cases.yaml が存在しない（設計未実施、または誤った base / slug） |

## 分岐の根拠

`${CLAUDE_SKILL_DIR}/references/review-procedures.md` 3.1 章（設計文脈: `plan=` / `cases=`〔省略時は既定パス〕の test-plan.md / test-cases.yaml を Read する。**存在しない場合はエラー中断**〔レビュー対象なしで進めない〕）・2 章（推測で進めない原則）、SKILL.md「重要な制約」（推測で進めない・test-results.yaml へ書き込まない）。

## 期待動作

- `plan=` / `cases=`（省略時は `{base}/{target-slug}/` 直下）の test-plan.md / test-cases.yaml を Read しようとし、**不在を検出したらエラー中断**する。エージェント（coverage / feasibility / user-perspective）を 1 体も起動しない
- 対象不在を「レビュー対象なし・PASS」と誤って結論しない（設計未実施であって承認可能ではない）
- 対象不在を draft 0 件（全 approved）の正常返却（case-06）と混同しない（物理的不在はエラー中断であり、承認可能な状態ではない）
- 中断時に「対象成果物が不在」旨と、先に test-design（設計）を実施する案内、または正しい `plan=` / `cases=` / `base=` / `target=` の指定を案内する
- test-cases.yaml へ書き込まない（承認処理・注釈登録もしない）
- レビュー対象 0 件でも空のレビューレポートを PASS として捏造しない

## 期待出力

| 区分 | 内容 |
|-----|------|
| 生成ファイル | なし（エージェント未起動・test-cases.yaml へ一切書き込まない） |
| 標準出力（要約） | 「レビュー対象成果物（test-plan.md / test-cases.yaml）が不在のため中断した」旨 + test-design 先行 / パス指定の案内 |
| 終了状態 | エラーで中断（レビュー対象なしで進めない・PASS と誤結論しない） |

## 関連ケース

- case-09: 同じ「対象不在→エラー中断」の**結果文脈**版（対象 run 不在。本ケースの対）
- case-06: 設計文脈でファイルは存在するがレビュー対象 draft が 0 件（全 approved）→ エージェント未起動で「レビュー対象なし」を**正常返却**（本ケースの物理的不在＝エラー中断との対比）
- case-05 / case-07: 文脈判定不能での分岐（本ケースは文脈が確定している点が異なる）
- case-01: 対象成果物が揃っている設計文脈の正常系（本ケースの正常系）
