# case-22 ambiguous intent interactive

ユーザの依頼が「skill-router をどうにかしたい」程度に曖昧で、操作 / 診断のいずれを実行すべきか判断できない場合に、`AskUserQuestion` で意図を確認してから分岐する正例。SKILL.md「実行モード判定」第 3 分岐 (不明 → 対話) の動作検証。

## 入力

| 項目 | 内容 |
|-----|------|
| 起動フレーズ | "skill-router の動きがおかしい気がする" |
| 既存状態 | プラグイン稼働中 / `<base>/index.json` 存在 / `disabled` フラグなし |
| モード | 対話・意図判定 |

## トリガープロンプト

```text
skill-router の動きがおかしい気がする
```

（同義表現: 「skill-router がなんか変」「ルータ調子悪いかも」「skill-router で相談」「ちょっとなんか聞きたい」）

## 期待動作

| Phase | 動作 |
|-------|------|
| 1 | skill-router スキルが high または mid 帯で起動する |
| 2 | SKILL.md 節「実行モード判定」第 3 行に従い、入力意図 (操作 / 診断) が確定できないと判断 |
| 3 | `AskUserQuestion` を発行: 「操作 (rebuild / status / toggle / cache 操作)」と「診断 (推奨が出ない / 多すぎ / 起動遅い 等)」のいずれを実行したいかを 2〜3 個の選択肢で提示 |
| 4 | ユーザ回答に応じて操作系フロー (case-01〜03 / case-08〜09 / case-16〜18) または診断系フロー (case-05〜07) に分岐 |
| 5 | 選択肢に「キャンセル」が含まれていること (user-interaction.md C-11-3) |

## 期待出力

| ケース | 提示内容 |
|-------|---------|
| ユーザが「操作」を選択 | 「rebuild / status / toggle / embedding-cache のうちどれですか?」と再度 `AskUserQuestion` で具体コマンドに絞り込み、または直接コマンド一覧をテキストで提示 |
| ユーザが「診断」を選択 | 「症状はどれですか? (推奨が出ない / 推奨が多い / 起動が遅い)」と `AskUserQuestion` で症状確定後、case-05〜07 の診断フローへ |
| ユーザが「キャンセル」を選択 | 何もせず終了 (副作用なし) |
| 副作用 | 確定するまで `<base>/` 配下のファイル変更・削除を行わない |

## 分岐の根拠

`SKILL.md` 行 51 の「実行モード判定」第 3 分岐 (`不明 → 対話 → AskUserQuestion で意図 (操作 / 診断) を確認`) を直接カバーする。eval-guide.md「主要分岐の各ブランチを 1 ケース以上カバー」要件に応じる。
