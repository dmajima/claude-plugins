# skill-router requirements
#
# These dependencies exist only for the optional local embedding-based
# routing.  venv_lifecycle installs them when the user opts in
# (``embedding.enabled = true`` in <venv-base>/config.json) and never
# otherwise, so a default install pays no download or disk cost.  With
# the feature disabled the router runs on the standard library alone;
# embedding_client also falls back to a no-op path if fastembed cannot
# be imported.
#
# Approximate disk footprint after install:
#   fastembed       ~400 MB (vendored onnxruntime wheels)
#   onnxruntime      ~80 MB
#   numpy            ~50 MB
#   model on first use  ~120 MB (paraphrase-multilingual-MiniLM-L12-v2)
# Total ~650 MB; remains under the 1 GB design budget.
#
# The venv is built under a user-owned directory (${CLAUDE_PLUGIN_DATA},
# else ~/.claude/.local/plugins/skill-router/) - never inside a checked-out
# repository, which could otherwise supply the interpreter the hooks run.
#
# Supply-chain note: this file pins version *ranges*, not hashes, so an
# install resolves whatever matching wheels the index serves at the time.
# For hash-verified installs, generate a lock file next to this one
# (requirements.lock); venv_lifecycle detects it and switches to
# `pip install --require-hashes -r requirements.lock`.  Generation steps are
# in the plugin README ("ハッシュ pinning" section).  No lock is shipped because the
# valid hash set is per-platform and would go stale in the repository.
#
# Construction, rebuild budget, backoff and TTL teardown are specified in
# the module docstring of references/scripts/routing/venv_lifecycle.py, which
# is the single source of truth for this lifecycle.  Do not restate the
# policy here; keep this file to the dependency list.

fastembed>=0.3,<1.0
numpy>=1.24,<3.0
# Pinned explicitly even though fastembed already depends on it: this
# lets operators apply CVE patches (or freeze a known-good version)
# without having to wait for a new fastembed release.  See security
# review M-6.
onnxruntime>=1.17,<2.0
